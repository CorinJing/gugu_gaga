## Godot 原型

当前 Godot 4.7 工程已接入桌面素材，可完整走通序章的**画面 demo**：

```text
project.godot
scenes/main.tscn                         标题画面
scenes/prologue/prologue_demo.tscn       当前序章 demo：船舱 → 船侧 → 码头 → 船夫 → 白鹭
scenes/prologue/prologue_end.tscn        序章结束
scenes/ui/game_hud.tscn                  共享 HUD：提示与物品栏
scripts/prologue/prologue_demo.gd        demo 状态流
assets/art/backgrounds/                  船舱关窗/开窗、船行驶、码头
assets/art/characters/                   白鹭夫人、船夫、服务生
assets/art/items/                        硬币正反面与透明硬币
```

### 屏幕适配

- **宽屏（≥1.45）**：4:3 舞台在左，物品栏在右。
- **4:3 / 近 4:3**：舞台填满窗口，物品栏变成顶部横条。
- **竖屏 / 方形**：舞台在上，物品栏在底部。
- 舞台保持 4:3，不拉伸；多余区域使用暗化背景，不出现硬黑边。
- 最小窗口 960×540。

当前 demo 流程：

```text
标题
  → 船舱（关窗）
  → 点击窗户（开窗）
  → 行李箱拿小刀 / 水桶拿鱼 / 喂白鹭得硬币
  → 离开船舱
  → 船侧行驶镜头
  → 码头
  → 船头（付船费）
  → 白鹭夫人：“你回来了。”
  → 序章结束
```

说明：

- 这一版是**美术接入 demo**，先把现有图跑起来。
- 旅馆门前“衣冠不整”的门锁、大厅和 113 还没接入这版 demo；旧 `hotel_exterior` 代码仍保留。
- 图上的 AI 水印在底部用暗角/提示条处理，正式版仍需重绘或去水印。
- 角色图目前是 3:4 居中展示，不是抠图；正式版需要透明切图。

运行方式：

```bash
open -a /Users/shiqi/Downloads/Godot.app --args --path /Users/shiqi/game-001-demo
```

或在 Godot 里打开 `project.godot`，按 `F5`。

## 本版最重要的三个决定

1. **风格向《Servant of the Lake》靠拢**：手绘质感、4:3 舞台、侧边物品栏、短气泡、物件特写、室内乐、日常恐怖。  
   但角色、世界观、谜题、文本全部原创，不拿 Vanderboom 家族、动物头晚宴、炼金术等具体内容。

2. **文本先于系统**：先确定玩家看到什么、听到什么、为什么在意，再决定用什么交互实现。

3. **范围收敛**：首版是 7 夜、7 个房间、7 条主谜题链、3 个结局，目标 2.5–3 小时。  
   不做开放世界、不做战斗、不做多主角。

4. **角色名统一为英文**：Lan Shen、Yanqiu Shen、Chao Shen、Madam Egret、Mr. Mole、Mr. Hare、Chef Carp、Miss Moth、Dr. Crow。  
   完整对照见 `游戏文本/00_文本总览.md`。
