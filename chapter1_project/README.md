# 第一章独立开发工程

这是第一章「113 号房」的独立 Godot 工程，和序章工程分开迭代。

## 运行

用 Godot 4.7.2 打开本目录的 `project.godot`，主场景直接进入第一章大堂。

## 内容

- 大堂：服务生、前台、登记簿、楼梯
- 走廊
- 113 号房：白鹭夫人、缝纫机、针线盒、穿针
- 章末后台空景与章节卡

## 合并前

第一章完成并验收后，再把 `scenes/ch1/`、`scripts/ch1/`、`assets/art/` 中对应资源合并回主工程。

当前独立工程使用桌面 `大堂.png`、`走廊.png`、`113房间内.jpg` 作为场景背景，服务生使用透明切图，站在大堂红毯中央。
