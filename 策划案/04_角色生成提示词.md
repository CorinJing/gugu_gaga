# 04 角色生成提示词

> 目标：生成接近 Rusty Lake /《Servant of the Lake》观看方式的手绘角色，但角色设定与服装保持《盐月旅馆》原创。  
> 适用：Midjourney / Stable Diffusion / 即梦 / 可灵 / DALL·E 等图像模型。  
> 本版只有三张角色立绘：Madam Egret、Ferryman、Hotel Waiter。玩家没有立绘；其他客人只做面具剪影。

## 八、参数建议

| 项目 | 建议 |
|---|---|
| 比例 | 角色立绘 3:4 或 2:3；头像 1:1 |
| 视角 | 正面 / 四分之三全身；同一角色固定一个角度 |
| 背景 | 纯深青、深棕或旧纸色；不要复杂场景 |
| 光线 | 柔和舞台光，左侧或右上方主光；所有角色统一方向 |
| 细节 | 中等细节，保留笔触；不要过度锐化 |
| 风格强度 | Midjourney 用 `--style raw`；SD 可加 `hand-painted 2D illustration` 权重 |
| 一致性 | 固定 seed、固定调色板、固定前缀；同一角色换动作时只改动作段 |

---

## 九、一致性技巧

1. **先定“角色锚点”**：脸型、面具、服装轮廓、主色、手持物，五样不变。
2. **同一角色只改三处**：表情、手部动作、光线角度；其他描述原样复制。
3. **先出纯背景立绘**，再合成到房间背景；不要让模型直接画复杂场景。
4. **同一项目统一纸纹和颗粒**：生成后统一加纸纹/颗粒，避免每张图像素质感不同。
5. **避免“完美对称”**：轻微不对称、歪领口、旧磨损，更像手绘。
6. **不要用“Rusty Lake character”当唯一描述**：要写出脸、服装、面具、配色、笔触，否则模型会随机发挥。

## 十、风格边界

- 可以学：手绘水彩/水粉、铅笔线、低饱和、旧纸、舞台光、略微拉长的脸、deadpan 表情、动物面具、1930 年代服装。
- 不要拿：Vanderboom 家族、Aldous/William/Alexandra、动物头晚宴、炼金术符号、具体角色五官与服装组合。
- 商用前确认所用模型的条款；本提示词只描述风格语言，不要求复制具体 IP 角色。
