## 六、接入 Godot 的拆分建议

| 图层 | 内容 | 说明 |
|---|---|---|
| `bg_hotel_exterior_base` | 墙体、屋顶、门框、窗、地面、盐沼、海面 | 固定背景，不含可交互小物件 |
| `door_closed` | 深绿色门板 | 关闭状态 |
| `door_open` | 打开后的门洞与门板 | 与关闭状态同注册点 |
| `time_lock_base` | 黄铜圆盘、白鹭刻纹、钥匙孔 | 固定层 |
| `ring_hour` / `ring_ten` / `ring_minute` | 三个同心刻度环 | 可旋转，注册点必须在圆心 |
| `door_lamp_on` / `door_lamp_off` | 门灯亮/灭 | 两张同尺寸切图 |
| `mailbox` / `umbrella_stand` / `doormat` | 小物件 | 单独透明 PNG，便于状态切换 |
| `clock_03_13` | 门上小铜钟 | 固定，03:13 |

### 交互热区

- 三个铜环：分别对应 `时 / 十分 / 分`，初始位置不要把正确数字直接对齐。
- 门：关闭时点击只提示“门锁着”；铜环对齐后播放开门状态。
- 信箱：可单独打开，内部不要提前画重要道具。
- 门垫：可掀起，底下可放钥匙或红线。
- 门灯：可亮/灭，作为氛围状态，不承载关键信息。

### 构图安全区

- 门锁圆盘放在画面中央偏上，避免被右侧道具栏遮住。
- 门灯和信箱不要贴边。
- 地面留出点击门垫的空间。
- 底部不要放关键线索；程序不在背景上叠加提示条，但仍需留出视觉呼吸区。
