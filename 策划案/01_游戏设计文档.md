### 一句话

> 潮水退去时，别忘了数一数家里的人。

### 玩家角色

Lan，27 岁，城里修表匠。离家十年，因母亲失踪回到栖潮镇，继承盐月旅馆。

她不是侦探。她是女儿、修表匠、临时守夜人。客人把她当服务员，母亲的声音把她当下一任守钟人，弟弟在 107 号房等她吃晚饭。

## 二、设计支柱

### 1. 家务即叙事

每一夜是一份值班表，而不是一张任务清单。玩家做的事情必须是旅馆里真实存在的家务：

- 送茶、补外套、修缝纫机；
- 量棺、挖坑、填土；
- 配显影液、冲洗底片；
- 生火、煮汤、摆第八副餐具；
- 上弦、调灯、弹摇篮曲；
- 整理药柜、填死亡证明；
- 摆两副碗筷、热汤、折纸船。

谜题不是“找钥匙”，而是“把一件事做完”。日常越具体，异常越可怕。

### 2. 一间房，一个人，一道伤

每夜只聚焦一位客人、一间客房、一条核心谜题链。

玩家离开房间时，必须多知道这个人的一个秘密；同时，旅馆公共区域要发生变化。玩家玩的是“人”，不是“关卡”。

### 3. 修复与放手

Lan 相信坏掉的东西都能修。

故事要教她：有些东西的“修好”，是让它停下；有些人的“留下”，是放他走。

## 三、核心循环

```
夜晚开始
  ↓
大厅：挂钟 / 登记簿 / 值班表 / 客人状态
  ↓
进入当晚客房
  ↓
日常任务（2–3 个小互动）
  ↓
核心谜题（多步骤）
  ↓
记忆碎片（盐唱片 / 闪回）
  ↓
获得潮针 + 客人的自白
  ↓
回到走廊：107 的动静
  ↓
夜间仪式：关灯、锁门、听 107
  ↓
下一夜
```

单夜目标时长：15–25 分钟。  
全流程目标时长：2.5–3 小时。

## 四、叙事结构

### 四幕

| 幕      | 章节          | 功能                                   |
| ------ | ----------- | ------------------------------------ |
| 第一幕：回来 | 序章、第一夜、第二夜  | 建立旅馆规则、六位客人、母亲之死；玩家以为自己是来处理遗产的       |
| 第二幕：看见 | 第三夜、第四夜、第五夜 | 照片、汤、摇篮曲逐层揭开十年前那晚；Lan 的记忆开始崩裂        |
| 第三幕：承认 | 第六夜、第七夜     | 死亡证明、107 号房；Lan 承认自己不是“被留下的人”，而是先走的人 |
| 第四幕：选择 | 终章          | 潮钟前做最终选择；三种结局                        |

### 叙事节拍

1. 母亲死了，但身体没找到。
2. 旅馆里有六位不肯退房的客人，每人少了一分钟。
3. Lan 在 101 找到第一枚潮针，听见母亲的声音。
4. 空棺、照片、汤、摇篮曲逐层证明：Chao 不是在她走后死的。
5. Dr. Crow 揭示：Lan 的记忆被盐唱片改写。
6. 107 号房出现；Chao 知道自己不是真的。
7. 潮钟前，Lan 决定：继续、归还、或打破。

### 三个结局

| 结局     | 操作                    | 情绪                 | 条件                       |
| ------ | --------------------- | ------------------ | ------------------------ |
| **守潮** | 七针插入，顺时针上弦            | 留住弟弟，成为下一任守潮人；循环继续 | 拥有七针                     |
| **退潮** | 六针归还，第七针还给 Chao，让钟自然停 | 放所有人走；Lan 失去部分记忆   | 完成六位客人的自白                |
| **盐月** | 卡住擒纵器                 | 打破循环；记住一切；真正告别     | 七针 + 母亲的信 + 纸船 + 六位客人的自白 |

> 结局不是最后突然出现的红蓝按钮。每一夜的“剪断/不剪”“烧掉/保留”“叫醒/让她睡”都在为最后的选择做铺垫。

## 六、七夜设计

### 第一夜：红线

**空间**：101，Madam Egret 的裁缝房。  
**日常**：送茶、补小外套、整理线轴、拉开窗帘。  
**核心谜题**：

1. 用剪刀剪断机头外的死结；
2. 用小螺丝刀拆开压脚、针板、梭床盖；
3. 用顶针把线拉出来；
4. 转动三个线圈，让三颗红珠落回同一条线上；
5. 取出潮针 1。

**秘密**：母亲把第一枚潮针缝进缝纫机；Madam Egret 那晚按住了 Lan，让她听完盐唱片。  
**选择**：剪断红线 / 不剪。  
**夜间仪式**：走廊尽头出现 107，男孩叫“姐姐”。

### 第二夜：空棺

**空间**：102、后院、白鹭树下。  
**日常**：给 Mr. Mole 倒酒、量棺材、挖坑、填土、守夜。  
**核心谜题**：

1. 用皮尺量出九岁男孩的棺尺寸；
2. 用砝码调平棺材盖上的秤；
3. 打开空棺：石头、纸船、空白死亡证明；
4. 从皮尺卷轴取出潮针 2。

**秘密**：母亲订了儿童棺，又让 Mr. Mole 填回去；没有尸体，只有一双鞋。  
**选择**：把纸船放回棺材 / 带走。  
**夜间仪式**：后院小坟；男孩问“姐姐，坑里冷吗？”

### 第三夜：合影

**空间**：103，暗房。  
**日常**：关灯、配显影液、冲洗三张底片、擦镜头、关红灯。  
**核心谜题**：

1. 按墙上的时间表配药水；
2. 控制三张照片的显影时间（8/12/16 秒）；
3. 按时间顺序排列，拼出完整合影；
4. 双重曝光，看见 03:13 的码头；
5. 从相纸夹层取出潮针 3。

**秘密**：照片证明 Lan 那晚在码头；Chao 追着她跑；Mr. Hare 举起相机，没有喊。  
**选择**：烧掉底片 / 保留。  
**夜间仪式**：走廊照片里的人都背对镜头；男孩问“照片里为什么没有你？”

### 第四夜：最后一顿饭

**空间**：104、厨房、餐厅。  
**日常**：清理灶膛、备菜、煮汤、关火、摆第八副餐具。  
**核心谜题**：

1. 用鱼骨卡住的风门修好灶台；
2. 按食谱找齐鱼、豆腐、红枣、长寿面；
3. 控制火候：大火煮沸 → 小火慢炖 → 关火焖七分钟；
4. 关火后从锅底取出潮针 4。

**秘密**：母亲在 03:14 浑身湿透来厨房，手里拎着 Chao 的鞋，说“他还没吃饭”。  
**选择**：把汤倒掉 / 留一碗。  
**夜间仪式**：餐厅长桌摆满七副餐具；男孩说“汤还是咸的。”

### 第五夜：摇篮曲

**空间**：105，琴房。  
**日常**：修八音盒、调三盏灯、找音符、弹摇篮曲、盖毯。  
**核心谜题**：

1. 用发条修好八音盒；
2. 根据墙上蜡笔画排列音符；
3. 调整灯光，让飞蛾影子落在五线谱上；
4. 弹奏摇篮曲，最后一个音故意不弹；
5. 从发条盒取出潮针 5。

**秘密**：Miss Moth 看见 Lan 推了弟弟，听见水声，却没有停。  
**选择**：叫醒她 / 让她睡。  
**夜间仪式**：105 的灯一盏盏熄灭；男孩说“姐姐，你唱歌跑调。”

### 第六夜：没有尸体的死亡证明

**空间**：106，诊所。  
**日常**：整理药柜、检查遗物、填死亡证明、盖章、烧档案。  
**核心谜题**：

1. 按标签颜色和有效期整理药瓶；
2. 用外套盐渍、血迹、码头照片、潮汐表推断落水时间；
3. 填写死亡证明，尸体一栏只能选“未发现”；
4. 在“确认死亡 / 未确认死亡”之间盖章；
5. 从封皮夹层取出潮针 6。

**秘密**：母亲跪下来求 Dr. Crow 签死亡证明；她给 Lan 注射镇静剂，让她听盐唱片改写记忆。  
**选择**：烧掉所有死亡证明 / 保留档案。  
**夜间仪式**：六间房门同时打开；107 出现；男孩说“姐姐，你终于数到我了。”

### 第七夜：107

**空间**：107，Chao 的房间。  
**日常**：摆两副碗筷、热汤、折纸船、调玩具钟、说晚安。  
**核心谜题**：

1. 把玩具钟从 03:13 调到 03:14；
2. 用六枚潮针临时校准齿轮；
3. 和 Chao 吃完最后一顿饭；
4. 接过第七枚潮针。

**秘密**：Chao 是母亲用盐、记忆和借来的时间维持的回声；他知道自己不是本人。  
**选择**：会留下来 / 不会 / 我不知道。  
**夜间仪式**：房间漏水；所有钟停在 03:13；母亲最后一段录音。

## 七、谜题设计

### 谜题语法

| 类型 | 说明         | 例子            |
| -- | ---------- | ------------- |
| 观察 | 从环境/物件读出信息 | 照片里的时间戳、衣领的红线 |
| 整理 | 按规则排列物品    | 药柜、餐具、照片顺序    |
| 顺序 | 按时间/步骤操作   | 火候、显影、拆机头     |
| 匹配 | 图形/声音/颜色对应 | 音符与灯光、线圈路径    |
| 物理 | 使用工具、开锁、测量 | 皮尺、螺丝刀、剪刀     |
| 社会 | 对话、选择、交付物品 | 登记、告白、最终选择    |

### 原则

- **没有失败惩罚**：谜题可重置，不扣道具，不限时。
- **错误有反馈**：错误顺序会给出具体提示，不是单纯“不对”。
- **提示分三层**：方向 → 具体物件 → 直接答案。
- **谜题必须暴露人物**：每解完一条链，玩家要知道客人的一个秘密。
- **不让像素级寻找**：可交互物有轻微金色描边/呼吸，热点足够大。
- **每个谜题都有一个“日常动作”**：缝、量、洗、煮、弹、盖章、修。

### 难度曲线

| 章节  | 难度   | 类型       |
| --- | ---- | -------- |
| 序章  | 教学   | 点击、对话、登记 |
| 101 | ★☆☆  | 工具使用、路径  |
| 102 | ★★☆  | 测量、逻辑    |
| 103 | ★★☆  | 观察、排序    |
| 104 | ★★★  | 状态管理、顺序  |
| 105 | ★★★  | 音画、光影    |
| 106 | ★★★☆ | 推理、证据    |
| 107 | ★☆☆  | 情感、对话    |
| 终章  | —    | 选择       |

## 八、系统与 UI

### 画面布局

```
┌──────────────────────────────┬────────────┐
│                              │  房间号    │
│                              │  值班表    │
│        960×720 主舞台        │  物品栏    │
│        （4:3，手绘画框）      │  怀表提示  │
│                              │  音效开关  │
│                              │            │
└──────────────────────────────┴────────────┘
```

- 主舞台：960×720，圆角画框，外侧暗角/黑边。
- 右侧栏：320×720，深色木纹/黄铜；纵向 8 格物品栏。
- 对话：短气泡，靠近说话者；不遮挡主舞台中心。
- 旁白：主舞台上方/下方一行小字，或全屏章节卡。
- 调查：底部一行物件描述；不打开大对话框。
- 章节卡：黑底、盐霜/黄铜边框、白字。

### 核心系统

| 系统  | 功能                       |
| --- | ------------------------ |
| 交互  | 点击热点、使用物品、组合、拖拽（少量）      |
| 物品栏 | 8 格；选中金色描边；悬停显示名称        |
| 值班表 | 每夜 3–5 项任务；完成盖章；不是通用任务栏  |
| 对话  | 短气泡、打字机、可跳过、可回看          |
| 记忆  | 盐唱片/闪回；全屏静止画面 + 旁白       |
| 存档  | 单槽自动存档；每夜开始/结束；章节选择      |
| 提示  | 母亲怀表；三层提示；不扣资源           |
| 章节卡 | 每夜开始/结束；时间过渡             |
| 无障碍 | 字幕、文字速度、色盲友好、无音频-only 谜题 |

### 旅馆变化

每夜结束后，公共区域至少变化一处：

- 挂钟倒退一分钟；
- 餐桌上多/少一副餐具；
- 墙上多一张照片；
- 门缝渗出红线/盐/水；
- 客人的动作改变；
- 107 的门更近一步。

## 十三、风险

| 风险      | 应对                             |
| ------- | ------------------------------ |
| 美术量过大   | 4:3 单舞台、固定机位、复用大厅变体；先做 101 样张  |
| 文本过长    | 单句 24 字以内；单屏 2 行；每夜只保留 1 个核心秘密 |
| 谜题与文本脱节 | 每个谜题先写“它让谁暴露了什么”，再写玩法          |
| 风格像但内容空 | 先锁人物关系与结局，再谈手绘/UI              |
| 玩家看不懂   | 三层提示；关键信息用盐唱片/客人/信件三条线重复       |
| 范围失控    | 7 夜、7 谜题、3 结局；不做开放世界/战斗/多主角    |
| 本地化困难   | 文本 ID 化；避免谐音梗；术语表统一            |
