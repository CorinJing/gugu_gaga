# 13 水桶中的鱼生成提示词

> 用途：船舱水桶里的死鱼道具 / 近景素材。  
> 当前画面需要一条普通的银色海鱼躺在旧铁皮水桶里，不要血腥、不要怪物化。

## 四、透明道具拆分建议

正式接入 Godot 时，建议不要只生成一张“鱼+桶”的合成图，而是分开：

| 图层 | 内容 | 说明 |
|---|---|---|
| `prop_bucket` | 空铁皮水桶 | 单独透明 PNG，含桶沿和提手 |
| `prop_fish` | 死鱼 | 单独透明 PNG，鱼身完整，尾巴可搭在桶沿上 |
| `water_surface` | 桶内浅水 | 可选，半透明层 |
| `bucket_shadow` | 桶底接触阴影 | 可选，叠在地板上 |

生成时可以先出“鱼+桶”的完整道具图，再用同样构图分别生成空桶和单独的鱼；也可以直接生成“鱼+桶”作为一次性背景物件。

透明底生成提示：

```text
Isolated on a flat neutral bone-gray background, no cast shadow beyond a small soft contact shadow, centered with generous empty margin, clean edges suitable for cutout, 1:1.
```

## 六、规格

```text
格式：PNG-24 / PNG-32
尺寸：1024×1024 或 2048×2048
色彩：sRGB
背景：透明，或纯骨白/中性灰便于抠图
画面：一条死鱼+旧铁皮水桶，无人物、无手、无 UI、无文字、无水印
```

鱼要保持“普通、安静、已经死去”，不要做成恐怖道具。
