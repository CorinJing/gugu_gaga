# 02 风格与文本规范

> 《盐月旅馆》｜v0.1  
> 目标：在**观看方式、质感、节奏、文本语气**上接近《Servant of the Lake》，但角色、世界观、谜题、美术资产全部原创。

---

## 一、先分清：风格与内容

### 可以主动靠拢的“风格层”

- 手绘水彩/水粉、铅笔底稿、纸纹；
- 低饱和配色、柔光、暗角、4:3 舞台；
- 固定机位、物件特写、静物构图；
- 右侧物品栏、短气泡、章节卡；
- 室内乐、房间底噪、每件物品独立音效；
- 日常家务 → 异常升级；
- 仆人/旁观者视角、冷幽默、礼貌的恐怖；
- 文本短、少解释、靠画面和动作。

### 必须原创的“内容层”

- Vanderboom 家族、Aldous/William/Alexandra、炼金术、灵药；
- 动物头客人、旅馆晚宴、记忆方块、湖中巨物；
- 具体谜题答案、房间构图、UI 皮肤文件、角色台词、美术资产；
- 血腥身体恐怖。

一句话：**学它的“怎么看”，不拿它的“看什么”。**

---

## 二、视觉风格

### 1. 画幅与舞台

- 基准分辨率：1280×720。
- 主舞台：960×720，4:3，圆角画框，外侧黑边/暗角。
- 右侧栏：320×720，深色木纹/黄铜，纵向物品栏。
- 固定机位；不自由移动、不旋转镜头。
- 解谜时推近物件；背景保留暗角，不切独立 UI 页面。
- 章节卡/记忆闪回可全屏，但保持同一画框语言。

### 2. 材质

- 水彩/水粉的湿边、沉淀、纸纹；
- 铅笔/炭笔底稿透出；
- 木头、布料、金属、瓷器有不同笔触；
- 避免纯平色块、过度干净的矢量边；
- 光边缘柔，阴影不纯黑，带环境色。

### 3. 色彩

| 角色 | 色值 | 用途 |
|---|---|---|
| 深海绿 | `#1b2b27` | 阴影、旅馆木墙 |
| 鼠尾草绿 | `#5d6b58` | 墙纸、布料、制服 |
| 骨白 | `#b9a88c` | 皮肤、旧纸、盐霜 |
| 纸白 | `#d8cdb0` | 高光、纸张、月光 |
| 铁锈红 | `#a34b3f` | 红线、血、窗光 |
| 黄铜 | `#c9a24e` | 钟、针、钥匙、灯光 |
| 深木 | `#3a2a20` | 家具、门框 |
| 灰粉 | `#b78b8e` | 床品、窗帘、客人衣料 |
| 盐白 | `#e8e1d5` | 盐、雾、结局 |

每章一个强调色：

- 101 红线红
- 102 泥土褐
- 103 显影琥珀
- 104 炉火橙
- 105 蛾翅灰
- 106 药瓶绿
- 107 海蓝

### 4. 角色与肖像

- 人脸略长，五官克制，表情不夸张。
- 肖像用油画感：柔边、厚涂、局部高光；不是扁平剪影。
- 客人戴瓷质动物面具；面具是“盐化后剩下的最后一点自我”，不是动物人。
- 面具表面有细裂纹；说出真话时裂纹扩大。
- Lan 不戴面具；她的疲惫要画在眼下、手背、衣领。
- 母亲只出现在盐唱片/照片/钟内幻影里；不要给她“完整活人”的立绘。
- Chao 永远是九岁；真结局短暂长大后，仍保留孩子的眼神。

### 5. 构图

- 每个房间先定一个“主物件”：缝纫机、棺材、暗房灯、汤锅、钢琴、药柜、纸船。
- 主物件占画面 1/3–1/2；角色在其后/其侧。
- 前景可放窗帘、门框、桌角、盐粒，制造层次。
- 室外/走廊用 2–3 层视差：远山/海、中景建筑、前景草/栏杆。
- 特写谜题：物件占满舞台，背景暗到只剩轮廓。
- 避免对称到死板；用一盏灯、一只手、一道水渍打破平衡。

### 6. 光影

- 暖黄台灯/壁炉 + 冷绿环境。
- 光要有来源：窗、灯、炉、唱片机、走廊尽头。
- 重要信息放在光里；秘密放在阴影边缘。
- 不使用彩色轮廓光、霓虹、过曝 Bloom。
- 夜晚不是纯黑；保留盐雾的灰绿。

### 7. UI

- 右侧栏：房间号、值班表、物品栏、怀表提示、声音开关。
- 物品栏 8 格，图标 48×48，选中金色描边。
- 对话：短气泡 + 小头像；靠近说话者；不挡主物件。
- 旁白：主舞台上方/下方一行小字；或全屏章节卡。
- 调查：底部一行物件描述；不打开大对话框。
- 章节卡：黑底、盐霜/黄铜边框、白字、一声钟/潮。
- 光标：黄铜钥匙/手指；悬停物件轻微发光。
- 不用通用任务列表、血条、经验值、迷你地图。

### 8. 动画

- 限制帧率感；物件轻微摆动、布料呼吸、灯焰抖动。
- 角色：眨眼、转头、手指动作；不做大幅行走。
- 转场：淡入淡出、推近、章节卡；不用花哨划屏。
- 恐怖瞬间：突然推近、静止、留白；不靠 jump scare 音效。

## 三、声音风格

### 1. 音乐

- 主奏：钢琴、竖琴、长笛、八音盒、低音弦乐。
- 一个主主题，按房间变奏：
  - 101 缝纫机节奏 + 钢琴；
  - 102 低音弦乐 + 泥土闷响；
  - 103 暗房红灯 + 单簧管/低频；
  - 104 炉火 + 低音提琴；
  - 105 八音盒 + 女声哼唱；
  - 106 药瓶碰撞 + 钟摆；
  - 107 海 + 钢琴单音。
- 关键真相时抽掉音乐，只留钟/潮/呼吸。
- 不全程铺满；留白是配器的一部分。

### 2. 环境音

每个空间一条底噪：

- 大厅：木地板、挂钟、远处海；
- 101：雨、缝纫机、布料摩擦；
- 102：泥土、皮尺、夜虫；
- 103：暗房药水、红灯电流、快门；
- 104：火、汤沸、锅铲；
- 105：琴弦、飞蛾撞灯；
- 106：药瓶、钟摆、纸页；
- 107：海、纸船、儿童呼吸；
- 地下室：钟、盐井滴水、低频。

### 3. 物件音效

每件可点物件都要有触感：

- 布料：闷、软、短；
- 木头：干、脆、低频；
- 金属：亮、短、带尾音；
- 纸张：薄、碎、轻；
- 瓷器：清、脆、短；
- 盐粒：细、沙、摩擦；
- 水：近、湿、低。

### 4. 人声

- Mother:盐唱片低语，轻微失真、低频、像从水底传来。
- 客人：短句、气声、不夸张；动物面具不改变声音。
- Lan：低、稳、少情绪；越接近真相，越轻。
- Chao：九岁孩子的声音，不装可爱，不装鬼。
- 不做全程配音；关键台词可配气声/低语。

## 四、文本规范

### 1. 叙述视角

- **旁白/调查文本**：第二人称“你”，指 Lan。
- **角色台词**：第一人称。
- **Lan 内心**：只在关键节点，用短句；不写长篇独白。
- **母亲**：只通过盐唱片/信件/幻影出现；句子短、家务化。
- **Chao**：孩子语言，问吃饭、睡觉、明天；不追问死亡。

### 2. 长度

| 类型 | 上限 |
|---|---|
| 对话气泡 | 2 行，每行 ≤ 24 汉字 |
| 旁白 | 2 行，每行 ≤ 28 汉字 |
| 物件描述 | 1 句，≤ 30 汉字 |
| 章节卡副标题 | ≤ 12 汉字 |
| 提示 | 3 层，每层 ≤ 40 汉字 |
| 连续旁白 | 不超过 2 屏 |

超过就拆，或让画面说。

### 3. 对话规则

- 每句只做一件事：推进、暴露、或留白。
- 不解释设定；让玩家先看见，再让角色说一句短话。
- 不写“你知道的……”式复述。
- 不写“其实我一直在骗你”式总结；让证据自己说话。
- 角色不轻易道歉、不轻易哭；情绪藏在动作里。
- 黑色幽默来自“他们觉得很正常”，不是讲笑话。
- 恐怖来自“语气太平静”，不是形容词堆砌。

### 4. 旁白规则

- 先写玩家能看到/听到/摸到的东西。
- 不写“她感到害怕”；写“你听见自己的呼吸变轻”。
- 不写“这里很诡异”；写“六副餐具，摆得很整齐。第七副没有人用。”
- 不写“时间过去了”；用钟、光、茶凉、汤面结盐。

### 5. 角色声音

完整台词库见 `游戏文本/03_角色台词库.md`，速记：

| 角色 | 声音 |
|---|---|
| Lan | 短、干、修理式；不说“我害怕”，说“这个零件松了” |
| Madam Egret | 轻、慢、礼貌；句子像针脚 |
| Mr. Mole | 粗、闷、黑色幽默；谈棺材像谈家具 |
| Mr. Hare | 快、滑、回避；用玩笑挡真话 |
| Chef Carp | 热、絮叨、家常；用汤和火说事 |
| Miss Moth | 轻、飘、失眠；句子短，常停顿 |
| Dr. Crow | 平、冷、准确；像在写病历 |
| Chao | 孩子、直接、不装可怜 |
| 母亲 | 家务化、命令式温柔；不说“我爱你” |
| 父亲 | 只留文字/明信片；短、像电报 |

### 6. 命名与术语

统一使用：

- 盐月、回声海、栖潮镇、沉町；
- 盐月旅馆、107 号房；
- 潮针、潮钟、借时、退房、盐化、盐唱片、守潮人；
- 第一夜/第二夜……第七夜；
- 潮针编号用阿拉伯数字 1–7。

不要混用：

- “潮针”不写成“时针”“盐针”；
- “退房”不写成“离开”“死亡”（除非角色故意委婉）；
- “盐唱片”不写成“记忆唱片”“留声片”；
- “107 号房”不写成“107 房”“四号房”。

### 7. 文本格式

剧本使用：

```
【场景】101 · 夜
【玩家可见】...
【设计注】...
角色：台词
```

全量文本使用：

```
ID：N1-OBJ-03
类型：物件观察
触发：缝纫机
文本：...
```

### 8. 本地化

- 文本全部 ID 化，避免硬编码。
- 不用谐音梗、方言梗、字形梗。
- 双关只保留“退房/死亡”“借时/借命”这类可解释的。
- 中文单句短，英文翻译时允许合并/拆分。
- 术语表随文本交付。

## 五、像与不像：示例

### 例 1：第一枚潮针

**不好的写法（解释太多）：**

> Madam Egret：你妈妈把第一根潮针缝进了缝纫机里。十年前，她用这根针借走了客人的时间，维持你弟弟的最后一分钟。

**好的写法（先看见，再短句）：**

> 【特写】针鼻上刻着 1。
>
> Lan：……第一根。
>
> Madam Egret：你妈妈缝的。她说，等岚回来，让她自己拆。

### 例 2：弟弟的死亡

**不好的写法：**

> Lan：都是我不好，如果那天我没有推他，他就不会掉进水里。

**好的写法：**

> Lan：我抓不住他。
>
> Dr. Crow：你抓住了。
>
> 【特写】她手腕上的红线。
>
> Dr. Crow：线断了。

### 例 3：日常恐怖

**不好的写法：**

> 这里非常恐怖，空气中弥漫着诡异的气息。

**好的写法：**

> 【大厅】六副餐具，摆得很整齐。
>
> 【旁白】第七副没有人用。汤还是热的。

### 例 4：黑色幽默

**Mr. Mole：**

> 棺材要朝南。你弟弟怕黑。
>
> ……朝北也行，就是下午晒。

### 例 5：母亲的温柔

**不好的写法：**

> Mother:岚，妈妈知道你恨我，但妈妈都是为了你好。

**好的写法：**

> Mother:汤在锅里。
>
> Mother:衣服在柜子里。
>
> Mother:别回来。

## 六、审查清单

- [ ] 这句话是谁说的？换一个角色说还成立吗？成立就删/改。
- [ ] 这句话现在非说不可吗？能不能让物件说？
- [ ] 这句是否在解释玩家已经看见的东西？
- [ ] 单句是否超过 24 字？气泡是否超过 2 行？
- [ ] 有没有“设定会”式对白？
- [ ] 有没有为了怪而怪的段落？
- [ ] 恐怖是否来自日常错位，而不是形容词？
- [ ] 角色是否用日常语气谈论异常？
- [ ] 画面/声音是否能替代这句文本？
- [ ] 术语是否统一？
