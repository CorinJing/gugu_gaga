# 16 第一章实现说明（113 号房）

> 范围：从「序章结束页」点进第一章，到「第一章 · 完」章节卡。
> 依据：`策划案/06_当前版本策划案_v1.md` 第 3 节「第一章 · 113 号房」。
> 状态：**流程已跑通、可自测通过**；背景为占位图，角色用现有切图。

---

## 一、流程

```
序章结束页（改成「进入第一章」）
  ↓
大堂：服务生「欢迎。请登记。」→ 再点 →「113 号房，白鹭夫人。她需要缝补。」
      拿到【服务单】→ 楼梯出现
  ↓
二楼走廊：点 113 门
  ↓
113 号房：白鹭夫人「线断了。」
      点针线盒 → 拿到【红线】
      把红线拖到缝纫机的针上 → 穿针成功 →「你母亲以前也穿过这根线。」
      再点针线盒 → 最下层 → 拿到【黄铜针】（针鼻刻 1）
  ↓
点房门离开 → 大堂空无一人（服务生不见了）
  ↓
点任意处 → 章节卡「第一章 · 完」
```

和策划案的差异只有一处：策划案写的是「帮她穿针、补外套」，实现里把「补外套」省掉了，只保留**穿针**这一个动作——因为手上没有针线的手部特写素材，硬做会变成纯点按。等有素材再补。

## 四、哪些是真图，哪些是占位

| 资源 | 状态 |
|---|---|
| 服务生、白鹭夫人 | **真图**（工程原有的透明切图） |
| 大堂 / 走廊 / 113 背景 | **占位**：按 `策划案/15_旅馆大堂生成提示词.md` 的构图用程序画的 |
| 服务单 / 红线 / 黄铜针图标 | **占位**：程序画的矢量感图标 |
| 字体、HUD、道具栏 | 真图（工程原有） |

占位图的构图是照提示词摆的：大堂右侧前台（铃、登记簿、钥匙板）、后方楼梯与走廊、中央长桌与烛台、左侧内门与高柜。**拿到真图后同名覆盖** `ch1_lobby.png` / `ch1_hall.png` / `ch1_113.png` 即可，热点位置不用改（除非构图差太多）。

`ch1_lobby_fg.png` 是从大堂图里抠出来的前台层，用来让服务生「站在柜台后面」。换真图后需要重抠一张同尺寸的。

## 六、已知限制

- 背景是占位图，不是最终美术。
- 白鹭夫人是**站姿**切图，策划案里她是坐着缝衣服——等坐姿素材。
- 「补外套」没有实现，只有穿针。
- 没有配音：服务生、白鹭夫人目前只有文字气泡（船夫那两句是原有 mp3）。
- 没有音乐/音效（音频包在 `assets/audio/` 里，尚未接线）。
- 章节卡是纯黑底 + 文字，没有做盐霜/黄铜边框。
