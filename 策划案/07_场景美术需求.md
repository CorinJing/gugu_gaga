# 07 场景美术需求 v1

> 范围：序章 + 第一章  
> 目标：给程序提供可直接接入 Godot 的场景背景、可交互物件状态、角色切图和 UI。  
> 前提：第一人称，玩家即主人公；不出现主人公的脸、身体、手、立绘、影子或配音。

---

## 一、先做什么，不做什么

### 先做

1. 三张序章场景：船舱、船头、旅馆门前。
2. 这三张场景的可交互物件状态。
3. 共享 UI：提示条、物品栏、按钮、物品图标。
4. 第一章：旅馆大厅、113 号房。
5. 白鹭夫人、船夫、服务生的透明切图与必要姿势。

### 暂不做

- 不做第二夜之后的房间。
- 不做 107、潮钟、三结局的场景。
- 不做主人公立绘、手部特写、第一人称身体。
- 不做战斗、追逐、跳吓。
- 不做大量逐帧动画；场景以静态手绘 + 少量状态切换为主。

---

## 二、技术规格

| 项目 | 规格 |
|---|---|
| 游戏窗口 | 1280×720 |
| 主舞台 | 960×720，4:3 |
| 右侧物品栏 | 320×720，由 UI 绘制，不画进背景 |
| 背景最终尺寸 | 1920×1440（2 倍），PNG |
| 背景安全区 | 960×720 内构图；四周不要放关键信息 |
| 角色切图 | 透明 PNG；3:4；建议 1200×1600 以上 |
| 物件切图 | 透明 PNG；按 2 倍尺寸导出 |
| 物品图标 | 256×256，透明 PNG |
| UI 九宫格 | 源图 64×64 或 128×128，可拉伸 |
| 色彩 | sRGB |
| 格式 | PNG-24/32；不要用 JPEG 存透明图 |
| 图层 | PSD / CLIP / Procreate 分层源文件 + 分层 PNG 导出 |

### 导入 Godot 的要求

- 背景与物件使用 `Filter` 开启，不要像素化。
- 物件切图保持同一画布尺寸和注册点，状态切换不能位移。
- 角色切图脚底/坐姿底部对齐，附一个基准线。
- 所有可交互物件单独导出，不要烘焙进背景。
- 热区由程序做；美术提供一张标注图即可。

## 三、视觉规范

### 风格

- 手绘 2D，水彩 / 水粉 / 旧纸质感。
- 轻微铅笔底稿、略有颤抖的墨线。
- 低饱和、旧、安静、礼貌的诡异。
- 参考《Servant of the Lake》的观看方式与空间感，但不复制其角色、构图和道具。
- 不追求照片写实，不做 3D/CGI，不做日漫/迪士尼。

### 色彩

| 用途 | 建议色 |
|---|---|
| 墨色/最深阴影 | `#1E2422` |
| 深绿 | `#33443D` |
| 鼠尾草绿 | `#6E7F6A` |
| 骨白 | `#E8DFC8` |
| 盐白 | `#C9C0A8` |
| 灰粉 | `#B58C86` |
| 铁锈红 | `#A34B3F` |
| 黄铜 | `#B08A4A` |
| 海水 | `#2B4B50` |
| 夜蓝 | `#162326` |

避免纯黑 `#000000` 和纯白 `#FFFFFF`；用深绿、炭黑、骨白代替。

### 光

- 单一主光源，方向明确。
- 船舱：左侧冷光（窗），右侧暖光（床头灯）。
- 船头：阴天冷光，低对比；旅馆远处有一点暖光。
- 旅馆门前：左上冷月光，门边一盏暖黄门灯。
- 大厅：烛光暖黄，背景深绿。
- 113：左侧冷窗光，缝纫机上方一盏暖灯。

### 透视

- 第一人称，视高约 1.5 米。
- 门高约 2.2 米，桌面约 0.8 米。
- 不要出现主人公的肩膀、手、影子或倒影。
- 镜头略低于人眼时更压迫；略高时更冷。序章用平视。

## 七、文件命名与图层

### 命名

```text
bg_cabin_base_v01.png
bg_cabin_window_open_v01.png
obj_cabin_suitcase_closed_v01.png
obj_cabin_suitcase_open_v01.png
obj_cabin_mattress_cut_v01.png
obj_cabin_coin_v01.png
char_egret_seated_v01.png
ui_panel_inventory_v01.png
item_knife_v01.png
```

规则：

- `bg_` 背景
- `obj_` 可交互物件/状态
- `char_` 角色
- `ui_` 界面
- `item_` 物品图标
- `fx_` 特效
- 版本号统一 `v01`、`v02`

### 图层

每张场景至少分：

1. `bg` 背景
2. `mid` 中景家具
3. `interact` 可交互物件
4. `fg` 前景遮挡
5. `light` 光效（可选）
6. `fx` 尘埃/水汽（可选）

不要把 UI、提示文字、物品栏画进背景。

### 热区标注

每张场景交一张 `*_hotspots.png`：

- 在场景图上用半透明色块标出可点击区域。
- 标注物件 ID，例如 `window`、`suitcase`、`mattress`、`coin`。
- 不要求精确到像素，但要和最终画面一致。

## 八、验收标准

- 在 960×720 下，所有关键物件一眼可辨。
- 背景与角色、物件的光向一致。
- 物件状态切换不位移、不跳色。
- 透明边缘干净，没有白边/黑边。
- 没有 AI 水印、没有多余手指、没有现代物品。
- 没有把提示文字、按钮、物品栏画进背景。
- 中文 UI 文字由程序渲染；招牌、信件、船票等叙事文字可以画进图，但必须另交一张无字版。
- 没有出现主人公的身体、手、影子、倒影。
- 画面安静、旧、低饱和；不出现高饱和霓虹、血腥、跳吓。
- 同一场景的所有状态放在同一画布尺寸里，程序可直接替换。

## 十、给美术同学的一句话

> 先画“空间和光”，再画“物件和状态”；不要先抠细节。  
> 所有可交互的东西都要能单独拿下来，所有状态都要能原位替换。  
> 玩家不在画面里，但玩家一定在看着这个房间。
