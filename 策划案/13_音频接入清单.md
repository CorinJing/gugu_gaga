# 13 音频接入清单（按游玩顺序）

> 配套：`12_音频资产清单_美术demo版.md`（按文件查）、`音频试听_demo.html`（试听）
> 本文件按**玩家经历的顺序**列，每一行是"玩家做了什么 → 放什么 → 同时停/压低什么"。
> 46 条音频，P0 30 条。图例：🎵 音乐 ｜ 🌊 底噪 ｜ 🔔 音效 ｜ 🖱 UI ｜ ⭐ Sting

---

## 0. 接入前提（三个全局决定）

| # | 决定 | 说明 |
|---|---|---|
| 0.1 | `AudioDirector` 做成 autoload | 音乐/底噪不挂在场景节点上，否则 `change_scene_to_file` 会切断声音 |
| 0.2 | 三条 bus：`Music` / `Ambience` / `SFX` | UI 并进 SFX 也行；Music -18 dB、Ambience -20 dB、SFX -8 dB 起步 |
| 0.3 | 转场规则固定 | 音乐 **0.3 s 淡出**、底噪 **0.8 s 交叉**；`SceneTransition` 的黑场 0.28/0.34 s 正好盖住 |

> 船夫对白响起时：`Ambience` 压 -4 dB、`Music` 压 -6 dB，说完 400 ms 恢复。

## 2. 逐场景清单（可直接当验收表）

### A. 标题画面 · `scenes/main.tscn`

- [ ] 进入标题 → 🎵 `mus_title_theme_v01.wav`（loop，-8 dB）
- [ ] 点「开始」→ 🖱 `ui_click_v01.wav`；音乐 0.3 s 淡出后切场景
- [ ] 点「退出」→ 🖱 `ui_click_v01.wav`

### B. 船舱 · 关窗 → 开窗

- [ ] 进入 `CABIN_CLOSED` → 🎵 `mus_cabin_warm_v01.wav` + 🌊 `amb_cabin_closed_v01.wav`
- [ ] 点击窗户（`_on_window_input`）→ 🔔 `sfx_window_latch_v01.wav`
- [ ] 转场到 `CABIN_OPEN` → 🔔 `sfx_window_open_v01.wav`；🌊 交叉到 `amb_cabin_open_v01.wav`（0.8 s）；音乐不停
- [ ] 点击床头柜 → 🔔 `sfx_nightstand_touch_v01.wav`；🌊 交叉到 `amb_interior_v01.wav`
- [ ] 点击纸条（第一次，`_on_note_hotspot_input`）→ 🖱 `ui_note_open_v01.wav`
- [ ] 点击关闭纸条（`hud._on_note_input`）→ 🖱 `ui_note_close_v01.wav`
- [ ] 再点纸条（收信）→ 🔔 `sfx_letter_take_v01.wav` + 🖱 `ui_item_gain_v01.wav`
- [ ] 点返回箭头 → 🖱 `ui_click_v01.wav`；🌊 回到 `amb_cabin_open_v01.wav`
- [ ] 点门（`_on_door_input`）→ 🔔 `sfx_door_cabin_v01.wav` → 转场 `BOAT`

### C. 船上

- [ ] 进入 `BOAT` → 🎵 `mus_boat_drift_v01.wav` + 🌊 `amb_boat_moving_v01.wav`；`mus_cabin_warm` 淡出
- [ ] 点击任意处（`_on_boat_click`）→ 🔔 `sfx_dock_step_v01.wav` → 转场 `FERRYMAN`；🌊 交叉到 `amb_dock_dusk_v01.wav`

### D. 码头 / 船夫

- [ ] 进入 `FERRYMAN` → 🎵 `mus_dock_dusk_v01.wav`（`mus_boat_drift` 淡出）
- [ ] 点船夫（第一次）→ 🖱 `ui_speech_pop_v01.wav` + 现有 `ferryman_01_unpaid.mp3`
- [ ] 点船夫（已付钱／重复点击）→ 现有 `ferryman_02_answer.mp3`（气泡音可省略）
- [ ] 拖硬币到船夫（`_pay_ferryman`）→ 🔔 `sfx_coin_palm_v01.wav` + 🖱 `ui_drop_ok_v01.wav` + 自动播 `ferryman_02_answer.mp3`
- [ ] 付钱后 → 🔔 `sfx_cloth_shift_v01.wav`（船夫侧身）
- [ ] 点船舱（未付钱）→ 🖱 `ui_click_v01.wav` → `CABIN_SEARCH`
- [ ] 点旅馆 → 🔔 `sfx_hotel_arrive_v01.wav` → 转场 `HOTEL_EXTERIOR`

### E. 船舱（回来搜东西）· `CABIN_SEARCH` / `CABIN_BEAK`

- [ ] 进入 → 🎵 `mus_cabin_warm` 恢复 + 🌊 `amb_cabin_open`
- [ ] 点箱子 → 🔔 `sfx_suitcase_open_v01.wav`；🌊 `amb_interior`
- [ ] 点小刀 → 🔔 `sfx_knife_take_v01.wav` + 🖱 `ui_item_gain_v01.wav`
- [ ] 点水桶拿鱼 → 🔔 `sfx_fish_take_v01.wav` + 🖱 `ui_item_gain_v01.wav`
- [ ] 点白鹭（已割前）→ 🔔 `sfx_heron_sewn_v01.wav`
- [ ] 拖小刀到白鹭（`_use_on_heron("knife")`）→ 🔔 `sfx_thread_cut_v01.wav` + 🔔 `sfx_beak_open_v01.wav` → `CABIN_BEAK`
- [ ] 拖鱼到白鹭（`_use_on_heron("fish")`）→ 🔔 `sfx_heron_swallow_v01.wav` → 0.85 s 后 🔔 `sfx_coin_drop_v01.wav`（对齐掉落补间）
- [ ] 点地上硬币（`_on_coin_pickup`）→ 🔔 `sfx_coin_pickup_v01.wav` + 🖱 `ui_item_gain_v01.wav`
- [ ] 点门离开 → 🔔 `sfx_door_cabin_v01.wav` → `FERRYMAN`
- [ ] 拖错东西 / 落到空处 → 🖱 `ui_drop_fail_v01.wav`

### F. 旅馆正门 / 信箱

- [ ] 进入 `HOTEL_EXTERIOR` → 🎵 `mus_hotel_night_v01.wav` + 🌊 `amb_hotel_night_v01.wav`

- [ ] 点门（`_on_hotel_door_open_input`）→ 🔔 `sfx_hotel_door_v01.wav`；音乐 1.4 s 内淡出

### G. 标题卡 / 结束页

- [ ] `PROLOGUE_LOGO` 出现 → ⭐ `sting_logo_v01.wav`；同时底噪全停（静场）
- [ ] 5 s 后切 `prologue_end.tscn` → 🎵 `mus_end_card_v01.wav`（单次）
- [ ] 点「回到标题」→ 🖱 `ui_click_v01.wav`；音乐淡出

### H. 全局 UI（任何场景都可能触发）

## 3. 需要程序改的四个地方

| # | 位置 | 改什么 |
|---|---|---|
| 3.1 | `_set_state()` 末尾 | 按 `match state` 调 `AudioDirector.set_scene("cabin_open")` 之类，由它统一决定音乐/底噪 |
| 3.2 | `_say_ferryman()` | 播 mp3 前 `AudioDirector.duck("voice", 0.45)`，结束后恢复 |
| 3.3 | `_on_item_dropped()` | 命中分支前放 `ui_drop_ok`，`else` 分支放 `ui_drop_fail` |
| 3.4 | `GameState.add_item()` | 成功入栏时 `AudioDirector.sfx("ui_item_gain")`（避免每处手写） |

## 4. 目前**不该**放声音的地方

- 场景切换的黑场本身（0.28 s）——已经有画面转场，再加 whoosh 会重复。
- 鼠标悬停——这版没有 hover 反馈，UI 音只在点击/拖拽时出现。
- 提示文字更新（`hud.set_prompt`）——纯文字，不需要音效。
- `WAITER` / `EGRET` 两个状态：代码里有，但这版把 `action_button` 隐藏了（`hud.set_action()` 是空实现），所以**当前不可达**。等它们接回来再补人声与状态音。
