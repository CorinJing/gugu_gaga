## 二、格式约定

### 剧本

```
【场景】N1-01 101 号房 · 夜
【画面】...
【玩家可见】...
【设计注】...
角色：台词
```

- `【场景】`：场景 ID + 地点 + 时间。
- `【画面】`：给美术/程序的舞台指示，不直接显示给玩家。
- `【玩家可见】`：玩家能看到的文字（旁白、物件描述、UI）。
- `【设计注】`：给策划/程序的谜题、flags、分支说明，不显示。
- `角色：台词`：角色台词；无名字的旁白用 `【旁白】`。

### 全量文本

```
ID：N1-OBJ-03
类型：物件观察
触发：缝纫机
文本：...
```

- ID 规则：`章节-类型-序号`
  - `UI-` 界面
  - `CARD-` 章节卡
  - `DUTY-` 值班表
  - `OBJ-` 物件观察
  - `ITEM-` 道具
  - `HINT-` 提示
  - `BARK-` 客人短句
  - `END-` 结局
- 文本必须能直接进游戏；注释放 `备注`。

## 七、写作口径

1. 单句 ≤ 24 汉字；单气泡 ≤ 2 行。
2. 旁白先写可见/可听/可摸，不写“恐怖”“诡异”。
3. 每场至少一个日常动作，一个异常细节。
4. 角色不解释设定；让证据先出现。
5. 黑色幽默来自“他们觉得很正常”。
6. 母亲不说“我爱你”；她说“汤在锅里”。
7. Lan 不说“我害怕”；她说“这个零件松了”。
8. Chao 不追问死亡；他问“你这次会留下来吗”。
9. 不写 jump scare；用重复、空白、错位。
10. 每句台词都要能回答：谁、为什么现在说、玩家在做什么。
