# 18 旅馆正门解谜：信箱钥匙

> 来自你的想法：船仓信件作为道具，投入信箱后，通过视角变化，信箱缩小成一把钥匙。  
> 原则：不用现成钥匙、不用密码、不用钟表、不用转盘；信箱本身就是钥匙。  
> 场景：旅馆正门，信箱、门、门灯、信箱旗都在画面里。

---

## 一、核心诡计

信箱不是收信的地方。

它是旅馆的**钥匙**，只是被做成信箱的样子。

玩家从船舱带来一封写着旅馆地址的信。把信投进信箱后，旅馆“读到”了收件人。  
这时视角开始变化：前景的信箱和门上的钥匙孔在透视里重叠。

玩家需要移动视角，让信箱的侧面轮廓和钥匙孔完全对齐。

对齐的一瞬间，信箱在视觉上缩小，滑进门上的钥匙孔——  
它变成了一把钥匙。

---

## 二、为什么不是普通机关

| 普通做法 | 本设计 |
|---|---|
| 找一把钥匙 | 信箱本身就是钥匙 |
| 把信交给 NPC | 把信投进邮箱，邮箱变成钥匙 |
| 使用道具点击门 | 先改变视角，让两个物体在透视里重合 |
| 钥匙是独立道具 | 钥匙由“信箱 + 信件 + 视角”共同产生 |
| 玩家操作物体 | 玩家操作的是**观看位置** |

这不是“用钥匙开门”，而是：

> 让信箱在正确的视角里，看起来像一把钥匙。

---

## 三、信件

### 来源

船舱床前箱子的近景里，除了小刀，还有一叠没拆的信。

最上面一封：

- 米白色旧信封
- 红色火漆印，压着一个小小的钥匙纹
- 收件人栏写着：`盐月旅馆 · 113`
- 没有寄件人

点击信件获得道具 `letter`。

> 为了保证不卡关，信件可以和小刀一起拿；如果玩家先拿了刀，再点信箱，会提示“信封还在箱子里”。

### 信件在道具栏中的样子

- 图标：一枚有火漆印的旧信封。
- 使用方式：拖到旅馆正门的信箱上。
- 不能直接拖到门上。

---

## 四、解谜流程

### 第一步：投信

在旅馆正门，把信件从道具栏拖到信箱。

信件消失。  
信箱旗自己抬起。  
信箱内部传来一声很轻的“咔”。

门上的窥视孔打开一条缝，看了一眼信箱。

### 第二步：视角变化

画面慢慢推近信箱。  
信箱在画面前景变得很大，门和钥匙孔在背景里变小。

门上的钥匙孔亮起一圈很细的黄铜线。  
它不是一个圆孔，而是一个**钥匙形状的凹槽**。

玩家现在可以：

- 左右拖动鼠标：改变观看角度
- 上下拖动鼠标：改变观看高度
- 信箱的轮廓会随着视角变化而倾斜、压缩

### 第三步：让信箱变成钥匙

玩家需要让信箱的**侧面轮廓**与门上的钥匙孔凹槽重合。

信箱本身的形状：

- 箱体 = 钥匙的柄
- 投信口 = 钥匙孔
- 信箱旗 = 钥匙的齿
- 立柱 = 钥匙的杆

当轮廓接近正确位置时，黄铜线会变亮。  
完全对齐时，“咔”一声，信箱沿着透视方向缩小，滑进门上的钥匙孔。

它变成了一把黄铜钥匙，插在门上。

### 第四节：转动钥匙

钥匙在锁孔里。

玩家拖动钥匙，顺时针转动。  
门开。

---

## 五、失败与反馈

- 视角不对：信箱仍然巨大，挡在门前；钥匙孔的黄铜线是暗的。
- 轮廓接近：黄铜线变亮，信箱边缘出现很细的金色描边。
- 完全对齐：信箱缩小、插入、变成钥匙。
- 没有信件：信箱只轻轻响一声，门上的窥视孔看一眼，合上。
- 投错物品：信箱把东西吐出来，不掉落、不消耗。
- 不需要文字提示；靠黄铜线、信箱旗和门缝的光反馈。

---

## 六、叙事

- 这封信没有寄件人，只有收件人：盐月旅馆 113。
- 旅馆只认“被寄来的地址”，不认站在门口的人。
- 信箱是旅馆的舌头，也是旅馆的钥匙。
- 玩家不是“拿钥匙开门”，而是让旅馆把自己收下。
- 门打开后，钥匙留在锁孔里，信箱空了。

轻微荒诞、礼貌、不恐怖。

---

## 七、实现拆分

### 所需资源

| 资源 | 说明 |
|---|---|
| `item_letter` | 带火漆印的信封图标，256×256 |
| `envelope_closeup` | 可选，信封近景/火漆印 |
| `mailbox_key` | 信箱轮廓对齐后变成的钥匙贴图 |
| `keyhole_outline` | 门上的钥匙形凹槽，黄铜线 |
| `mailbox_sprite` | 从旅馆正门背景中抠出的信箱，用于前景缩放 |
| `perspective_overlay` | 视角模式的全屏层 |

### 状态

```text
hotel_idle
letter_in_mailbox
perspective_mode
aligned
key_inserted
door_open
```

### 交互

- 信件：拖到信箱热区，触发 `letter_in_mailbox`。
- 视角模式：鼠标拖动改变 `view_x` / `view_y`。
- 信箱 sprite 的 `scale` 和 `rotation` 随视角变化。
- 信箱轮廓与钥匙孔凹槽的距离小于阈值时，吸附。
- 吸附后播放缩小、插入、变钥匙动画。
- 拖动钥匙旋转，播放开门。

### 视觉

- 信箱轮廓用黄铜线，不要发光过强。
- 视角变化用缓动，不要眩晕。
- 信箱缩小时保留透视，不要突然变成平面图标。
- 门开时只增加一条暖光，不做复杂内部场景。

---

## 八、与现有流程的接入

当前流程：

```text
付船费
→ 船夫第二句
→ 点击右侧旅馆
→ 旅馆正门
```

在这个方案中：

```text
船舱：从箱子拿到信件
→ 离开船舱
→ 旅馆正门
→ 把信投进信箱
→ 视角对齐
→ 信箱变钥匙
→ 开门
```

如果玩家没有拿信：

- 门可以正常靠近；
- 信箱提示“还缺一封写着旅馆地址的信”；
- 玩家可以回船舱拿信（需要在付船费前保留回船舱的路径，或在正门提供一次返回）。

---

## 九、推荐实现顺序

1. 先做信件道具和信箱热区。
2. 再做“投信后视角推近”的过场。
3. 用简化信箱 sprite + 钥匙孔轮廓做对齐 demo。
4. 对齐后播放信箱缩小成钥匙。
5. 最后接开门和序章结束。

这个方案比“影子客人”少一层物件调度，但多了一层真正的**透视/尺度解谜**，而且和“信件”这个叙事道具强绑定。
