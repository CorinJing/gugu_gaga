# 22 113 解谜 XMind 拆解

> 来源：桌面 `113号房间解谜.xmind`  
> 用途：把思维导图整理成可执行流程，并补上目前缺失的“线”和“针”的获得方法。  
> 当前已接入：楼梯、玩偶、113 号房、白鹭夫人坐姿。

---

## 一、XMind 原始结构

```text
113号房间解谜
├─ 1. NPC 提示玩家需要拿到线
│  ├─ 玩家在楼梯转角拿到玩偶
│  ├─ 玩家来到一楼大堂的阳台发现炉子
│  │  ├─ 阳台（包含小型喷泉）
│  │  └─ 炉子
│  │     └─ 有余力考虑如何点燃炉子
│  ├─ 玩家在杂物间发现一口锅
│  ├─ 玩家在阳台的小喷泉处获得盛满水的锅

├─ 2. NPC 提示玩家需要获得针

└─ 4. 结尾停留在哪里？
```

## 二、建议补完的流程

### 第一阶段：线

```text
白鹭夫人：“线断了。线在大堂。”
玩家离开 113。

大堂
→ 进入阳台
→ 发现炉子和小喷泉
→ 去杂物间
→ 拿到锅

回到阳台
→ 在喷泉处把锅装满水
→ 把锅放到炉子上
→ 把布偶放进锅里

炉子上的水烧开
→ 布偶的缝线松开
→ 水面浮出一根红线
→ 点击获得「红线」
→ 锅和布偶留在阳台
```

#### 为什么玩偶会变成线

布偶本来就是用旧窗帘布和红线缝起来的。  
水烧开后，缝线松开，布偶散成一锅布片和线。  
这是“把玩偶拆回材料”，不是煮活物；没有血、没有身体。

#### 炉子点燃

思维导图里写“有余力再做”。建议第一版**不强制点火**：

- 炉子默认是热的，或者
- 玩家把锅放上去后，炉子自动亮起。

后续如果要加点火谜题，可以用：

```text
走廊的蜡烛 → 点燃炉子
```

但不要影响主线。

### 第二阶段：针

```text
白鹭夫人：“线有了，还缺一根针。”
玩家去旅馆正门外的伞架。
→ 拿到一把旧雨伞。
→ 回到杂物间/阳台。
→ 用剪刀剪开伞布，取出伞骨。
→ 伞骨变成一根长针。
```

#### 伞 → 针的具体做法

建议在杂物间增加一把**剪刀**：

```text
旧雨伞 + 剪刀 → 去掉伞布 → 伞骨
伞骨 → 长针
```

这样比“徒手撕伞布”清楚，也比再加一个炉子烧伞布简单。

#### 为什么伞骨是针

旧雨伞的伞骨又长又细，前端尖，正好可以当一根粗针。  
白鹭夫人不需要绣花针，她需要的是能穿过厚外套的长针。

### 第三阶段：交针

```text
回到 113
→ 把红线交给白鹭夫人
→ 她穿针
→ 玩家把长针交给她
→ 她缝完蓝色外套
→ 从衣角抽出黄铜针（针鼻刻 1）
→ 第一章结束
```

---

## 三、还缺的两个问题

### 3. 解谜结束后场景/效果是什么？

建议：

```text
白鹭夫人缝完外套
→ 房间灯光变暖
→ 缝纫机停下
→ 她把手里的黄铜针递向玩家
→ 镜头停在黄铜针特写
→ 淡出
→ 第一章结束卡
```

不要立刻回大堂，先把“针”作为章节收束。

### 4. 结尾停留在哪里？

建议停在：

```text
113 号房 · 缝纫机前
黄铜针特写，针鼻上的“1”
```

然后出现章节卡：

```text
第一章 · 完
```

是否回大堂、是否进入下一章，留给下一章开场。

## 五、需要你确认的点

1. 玩偶是否按“煮开缝线”的方式变成红线？
2. 雨伞是否用剪刀剪开，取伞骨当针？
3. 解谜结束是否停在黄铜针特写，然后第一章结束？

如果没有异议，下一步就可以按这个顺序接：

```text
楼梯玩偶
→ 阳台炉子/喷泉
→ 杂物间锅/剪刀
→ 煮玩偶取线
→ 正门外雨伞
→ 剪伞取针
→ 回 113 交线交针
→ 黄铜针
→ 第一章结束
```
