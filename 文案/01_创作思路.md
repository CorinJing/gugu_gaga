# 01 创作思路

## 一、创作目标

做一款“玩完之后会安静一会儿”的 2D 点击式解谜游戏：

- 表面是**超现实旅馆怪谈**：动物面具的客人、会消失的房间、停在 03:13 的钟。
- 内里是**一个家庭的创伤故事**：母亲不肯放手，女儿不敢回头，弟弟被困在最后一分钟里。
- 谜题不是剧情的障碍，而是**角色心理的物化**：缝纫、测量、显影、烹饪、摇篮曲、验尸、修钟——每一道谜题都在问同一个问题：  
  **你要把失去的人，留在哪一格时间里？**

---

## 二、四个背景故事提案

### 提案 A｜《盐月旅馆》（最终采用）

**一句话**：离家十年的修表匠回到海滨故乡，继承母亲留下的七室旅馆；她必须在七个夜晚里取回七枚“潮针”，修好地下室那口停在弟弟死亡时刻的钟。

**核心设定**：盐会记住一切。海水退去时，被淹没的旧镇会露出来；旅馆的客人用“一分钟”换取不被海水溶解的停留。母亲用六位客人的时间和儿子最后一分钟，把溺死的儿子留在了 107 号房。

**气质**：潮湿、安静、盐白与锈红；家庭伦理包裹在民俗怪谈里。

**为什么适合游戏**：单一封闭场景、七个可独立设计的房间、天然的章节结构、道具与机关高度可视化。

---

### 提案 B｜《耳语剧场》

**一句话**：在一座只演给死人看的剧场里，提词员发现每一场戏都会从观众脑中抹去一个名字；今晚的剧目，演的是她自己的葬礼。

**核心设定**：剧场地下有台“记忆绞盘”，演员用观众的回忆作燃料。舞台机关、灯光、幕布、音效都可以变成谜题。

**优点**：视觉华丽，谜题与表演结合度高。  
**风险**：角色较多，叙事容易散；舞台空间不如旅馆房间那样天然分区。

---

### 提案 C｜《第九号温室》

**一句话**：植物学家在封闭温室里培育“记忆作物”，每一株植物都长着某个人的一段人生；第九号温室里，长出了她死去妹妹的脸。

**核心设定**：浇水、嫁接、光照、授粉都是解谜手段；不同的记忆会开出不同的花。  
**优点**：美术辨识度极高，色彩丰富。  
**风险**：偏科幻/生物，和“家庭旅馆”的亲密感相比，情感距离更远；谜题设计容易变成单纯的植物图鉴。

---

### 提案 D｜《沉没邮局》

**一句话**：一名邮差每天把信送到被海水淹没的旧城，收件人都是死人；直到他收到一封寄给自己的信，邮戳日期是明天。

**核心设定**：通过信封、地址、邮戳、火漆、投递路线解谜；每个死者都有一封未寄出的信。  
**优点**：天然适合章节化，情感浓度高。  
**风险**：场景跨度大，需要大量外景；和“旅馆”相比，缺少一个固定的、可反复探索的核心空间。

---

## 三、为什么最终选择《盐月旅馆》

1. **空间即结构**  
   旅馆有七间客房、一个大厅、一间厨房、一个地下室。玩家不需要记住复杂地图，却能反复回到同一空间，逐渐发现“同一间房在不同夜晚变了”。

2. **房间即人物**  
   每一间客房就是一位客人的心理切片。玩家进入房间，不只是找钥匙，而是在读一个人的一生。

3. **谜题即隐喻**  
   - 缝纫：把断裂的关系重新缝起来。
   - 测量：给一个没有尸体的孩子量棺材。
   - 显影：从一张合影里找出被抹掉的人。
   - 烹饪：为永远不会回来的孩子做最后一顿饭。
   - 摇篮曲：哄一个睡不着的大人。
   - 验尸：在一张假的死亡证明上签字。
   - 修钟：决定时间该继续，还是该停。
   
   这些动作天然适合点击式解谜，也天然承载情绪。

4. **体量可控**  
   单场景、七章节、固定视角、2D 手绘，适合小型团队甚至个人开发。第一阶段可以先做“101 号房”的垂直切片，验证交互与氛围。

5. **情感闭环**  
   故事最终不是“打败怪物”，而是“允许告别”。这给玩家一个可以带走的东西。

## 四、主题与情感内核

### 1. 爱与控制

母亲 Yanqiu 不是反派。她只是相信：**只要钟不走，孩子就还在。**

她把旅馆变成一台巨大的生命维持装置，用六位客人的一分钟，维持儿子最后一小时的循环。她救了儿子，也囚禁了所有人。她的爱是真的，伤害也是真的。

### 2. 记忆与存在

107 号房里的“Chao”不是鬼，也不是复活的人。他是母亲用盐、时间和记忆拼成的**回声**。他会记得姐姐，会撒娇，会问“你这次会留下来吗”，但他也知道自己不该存在。

玩家要面对的问题是：  
**如果一个东西拥有全部的记忆和感情，它是否配拥有一个结局？**

### 3. 离开与回来

Lan 离家十年，从没拆过母亲的信。她以为不回头就能不内疚。游戏让她一层层拆开那些信，也拆开自己篡改过的记忆。

最终她发现：弟弟不是在她离开后死的，而是在她离开的那一夜，跟着她走到了码头。

### 4. 修复的两种含义

Lan 是修表匠。她的职业信念是“坏掉的东西都能修”。  
但故事要教她：有些东西的“修好”，是让它停下；有些人的“留下”，是放他走。

## 五、与 Rusty Lake 的关系

我们学习的是**方法论**，不是表面符号：

| Rusty Lake 的手法 | 本作的转化 |
|---|---|
| 封闭空间中的超现实房间 | 海滨旅馆的七间客房，每间一个心理主题 |
| 动物头居民 | 客人戴着“记忆面具”；面具是身份被盐侵蚀后的残留，不是种族设定 |
| 记忆方块 | “盐唱片”“潮针”“旅馆登记簿”——记忆以盐晶、黄铜和纸的形式保存 |
| 循环与家族秘密 | 七夜循环、母亲与女儿、被留在最后一分钟里的弟弟 |
| 荒诞逻辑谜题 | 谜题逻辑来自旅馆的日常仪式：入住、缝补、做饭、拍照、守夜 |
| 冷幽默与突然的暴力 | 更克制的黑色幽默；恐怖来自“重复”和“等待”，不靠血腥 |

**明确不做的**：
- 不使用方块、湖中巨物、猫头鹰/鹿头等 Rusty Lake 标志性符号。
- 不复制“记忆方块”式的核心收集物。
- 不为了怪而怪；每个超现实元素都要能在情感上解释。

**本作的独特钩子**：
> **“借时”**——住客用一分钟换取停留，旅馆用这些分钟维持一个死者的最后一小时。  
> 玩家收集的不是钥匙，是别人生命里的七分钟。

## 六、叙事原则

1. **先给画面，再给解释**  
   每个章节先用一个强视觉意象抓住玩家：红线、空棺、显影液里的脸、永远沸腾的锅、停在 03:13 的钟。解释可以迟到，画面不能。

2. **每个谜题都要让角色暴露一点秘密**  
   玩家修好一台缝纫机，不只是拿到针，还会读到鹭夫人为什么把红线缝进孩子的衣领。

3. **不把母亲写成单纯的坏人**  
   她的控制欲、她的温柔、她的谎言，要同时成立。玩家应该在某一刻理解她，又在下一刻拒绝她。

4. **恐怖来自日常的错位**  
   客人礼貌、旅馆整洁、晚餐丰盛。只是所有人的脸都模糊了，窗外没有海，钟表都在倒着走。

5. **不要解释所有事**  
   盐为什么有记忆？旅馆为什么有 107 号房？有些问题给规则，不给原理。留白是氛围的一部分。

6. **让玩家做一次真正的选择**  
   结局不是 QTE，也不是“选红药丸/蓝药丸”。玩家在理解全部真相后，决定是否让钟继续走。

## 七、美学方向

### 视觉

- **风格**：2D 手绘 + 纸张纹理 + 轻微定格动画感；固定机位，单房间构图。
- **比例**：16:9，建议基准分辨率 1280×720；角色约 1/4 屏高，保证点击区域清晰。
- **色彩**：
  - 盐白 `#E8E1D5`
  - 骨灰 `#B9B3A8`
  - 锈红 `#A33B32`
  - 墨黑 `#1C2426`
  - 深海绿 `#1F3B3A`
  - 月光黄 `#D8D2B0`
- **每章一个强调色**：101 红线红、102 泥土褐、103 显影液琥珀、104 炉火橙、105 蛾翅灰、106 药瓶绿、107 海蓝。
- **角色**：人类身体 + 瓷质动物面具。面具表面有细裂纹；当角色说出真话时，裂纹扩大，面具下露出模糊的、像旧照片一样的人脸。
- **UI**：旅馆登记簿作为主菜单/章节选择；物品栏是一只旧缝纫盒；存档点是前台电话。

### 听觉

- 环境：远处的潮声、木地板、钟摆、风穿过窗缝、盐粒摩擦。
- 音乐：慢速钢琴、八音盒、低音弦乐、雾笛。关键真相时刻**留白**，只保留钟声。
- 配音：母亲只通过盐唱片出现，声音有轻微失真；客人以文字为主，关键台词可配气声。
- 禁止：廉价 jump scare、突然的全屏鬼脸。

---

## 八、规模与落地

### 首版目标

- 7 个主章节 + 序章 + 终章
- 7 个主谜题 + 10 个左右小谜题
- 约 30–40 个固定场景/特写
- 3 个结局
- 2–3 小时流程

### 开发顺序建议

1. **垂直切片**：序章 + 101 号房（鹭夫人），完整实现点击、物品栏、对话、一个多步骤谜题、一个记忆片段。
2. **系统沉淀**：把谜题、对话、场景切换、存档做成可复用组件。
3. **内容量产**：按“一个房间 = 一个角色 = 一个谜题链 = 一段真相”的模板推进。
4. **结局与打磨**：最后做地下室钟楼与三种结局，确保分支条件清晰。

### 标题备选

- **《盐月旅馆》**（首选）
- 《退潮旅馆》
- 《107 号房》
- 《第十三小时》
- 《给活人留的房间》

### 宣传语备选

- “潮水退去时，别忘了数一数家里的人。”
- “有些房间，是留给回不来的人的。”
- “钟停了十年，他还在等你吃晚饭。”
- “你要修好它，还是让它永远停下去？”
