# 05 游戏流程与谜题蓝图

> 本文件是阶段一的“可开发化”收尾：把故事拆成章节、谜题链和程序需求。  
> 阶段二可以直接从“序章 + 101 号房”的垂直切片开始。

---

## 一、设计支柱

1. **一间房，一个人，一道伤**  
   每个章节只聚焦一位客人、一个房间、一个核心谜题链。玩家离开房间时，必须对这个人的秘密多知道一点。

2. **谜题是心理动作**  
   不是“找三把钥匙开一扇门”，而是“替一个母亲缝完孩子的衣服”“给一个没有尸体的孩子量棺材”“让一锅热了十年的汤终于熄灭”。

3. **恐怖来自重复**  
   客人每天做同一件事，说同一句话，吃同一顿饭。玩家第一次觉得怪，第三次觉得可怜，第七次觉得害怕。

4. **没有失败，只有不愿意面对**  
   不做死亡惩罚、不做限时追杀。谜题可以重置，对话可以重看。唯一的“失败”是玩家选择继续维持循环。

5. **选择在最后，但伏笔在每一章**  
   三种结局不是最后突然出现的选择题。每位客人的去留、每根潮针的归还，都在为最后的决定做铺垫。

---

## 二、核心循环

```
进入夜晚
  ↓
大厅：客人状态变化 / 新对话 / 新区域解锁
  ↓
客房：观察 → 对话 → 找道具 → 解谜 → 获得潮针
  ↓
记忆：盐唱片 / 闪回 / 真相碎片
  ↓
回到大厅：客人反应 / 旅馆变化 / 107 更近一步
  ↓
下一夜
```

单章目标时长：15–25 分钟。  
全流程目标时长：2–3 小时。

---

## 三、章节流程

### 序章 · 最后一班渡船

**场景**：渡口 → 盐沼 → 旅馆门廊 → 前台 → 大厅 → 二楼走廊

**目标**：进入旅馆，完成入住登记，认识六位客人。

**流程**：
1. 渡船靠岸。玩家控制 Lan，点击渡口、盐沼、远处的灯塔，建立环境。
2. 旅馆门自动打开。Madam Egret 迎接。
3. 前台登记簿：玩家输入/确认姓名（默认“Lan”），发现入住日期是十年前。
4. 大厅环游：六位客人各自坐在固定位置。对话只给碎片，不解释设定。
5. 留声机播放母亲的第一段录音：“岚，不要把钟修好。”
6. 走廊尽头传来男孩哼歌。玩家走过去，看见湿脚印和一闪而过的 107 门牌。
7. 第一夜开始。

**教学**：点击、观察、对话、物品栏、档案（登记簿）。

**情绪目标**：让玩家觉得“这里不对”，但说不清哪里不对。

---

### 第一夜 · 红线（101 / Madam Egret）

**目标**：修好缝纫机，取回第一枚潮针。

**谜题链**：
1. **进入 101**：门锁着。钥匙板上没有 101 的钥匙，但 Madam Egret 在门内说“门没锁”。玩家推门即开。
2. **检查缝纫机**：机头卡住，梭床缠着红线。
3. **找工具**：在针线篮里找到小螺丝刀；在人台上找到顶针；在窗帘后找到剪刀。
4. **拆机头**：小游戏——按顺序拆下压脚、针板、梭床盖（点击顺序，错了可重来）。
5. **理线**：红线路径小游戏。线从梭床穿过三个孔，玩家需要旋转线轴，让线不交叉地通过。错误路径会让线缠得更紧；正确路径会露出针。
6. **取针**：第一枚潮针。
7. **记忆闪回**：母亲在灯下缝衣领，说“线断了，人就找不到了”。玩家点击衣领上的线头，闪回结束。
8. **Madam Egret 的 confession**：她承认那晚按住了 Lan。

**关键选择**：最后 Madam Egret 问“你要剪断吗？”  
- 剪断：她沉默，给你针，但少一段对话。  
- 不剪：她摘下一只手套，露出被线勒伤的手，给你针和额外线索。  
（不影响主线，影响真结局的“理解”计数。）

**获得**：潮针 1、红线（可缠绕在手腕上）、童装外套。

**旅馆变化**：大厅挂钟倒退一分钟；101 门缝下开始渗出红线。

---

### 第二夜 · 空棺（102 / Mr. Mole）

**目标**：量出棺材尺寸，打开空棺，取回第二枚潮针。

**谜题链**：
1. **找皮尺**：Mr. Mole 把皮尺借给 Lan，但皮尺卡住了。需要先帮他把酒瓶从工具箱里拿出来。
2. **测量**：用皮尺量房间里的棺材模型、门框、床。玩家需要推断“九岁男孩”的身高，并从登记簿里找到 Chao 的入住记录。
3. **调平秤**：棺材盖上有四个砝码，需按“年龄/年份”调平。提示来自墙上的身高刻度和母亲的记账本。
4. **开棺**：棺材里不是尸体，是石头、一只纸船、一张空白的死亡证明。
5. **取针**：皮尺卷轴里，潮针 2。
6. **记忆闪回**：母亲站在空坑边，说“没有尸体，也得有个地方可以去看他”。
7. ** confession**：Mr. Mole 承认自己收了银牙，也知道 Chao“没死透”。

**关键选择**：把纸船放回棺材，或带走。  
- 放回：获得“安葬”flag，真结局可用。  
- 带走：获得纸船，后续 107 对话多一句。

**获得**：潮针 2、银牙、纸船（可选）。

**旅馆变化**：后院多出一座小坟；餐厅的第八副餐具被摆正。

---

### 第三夜 · 少一个人的合影（103 / Mr. Hare）

**目标**：冲洗底片，从合影里找出 Chao 最后的位置，取回第三枚潮针。

**谜题链**：
1. **暗房准备**：关灯、开红灯、配显影液（三种药水比例，提示在墙上的冲洗时间表）。
2. **显影**：三张底片，分别显影 8 秒、12 秒、16 秒。时间过长会全黑，过短会太淡；可重来。
3. **排序**：把三张照片按时间顺序放在灯箱上。正确顺序会拼出一张完整的合影。
4. **找不同**：点击照片里的异常处——门口的半张脸、少了一角的蓝外套、窗外的纸船。
5. **双重曝光**：把合影与码头夜景叠放，看见 Chao 在 03:13 追出门。
6. **取针**：相纸夹层里的潮针 3。
7. **记忆闪回**：母亲在照片背面写字：“不是他的错。也不是她的。”
8. ** confession**：Mr. Hare 承认自己拍了照，没有喊人。

**关键选择**：烧掉底片，或保留。  
- 烧掉：Mr. Hare 松一口气，但真结局少一张证物。  
- 保留：他崩溃，承认自己把照片卖给了小报。

**获得**：潮针 3、合影、码头照片。

**旅馆变化**：走廊墙上多出一排照片，每张照片里的人都背对镜头。

---

### 第四夜 · 最后一顿饭（104 / Chef Carp）

**目标**：修好灶台，煮完那锅汤，取回第四枚潮针。

**谜题链**：
1. **修风门**：灶膛被鱼骨卡住，火快灭了。玩家需要拆风门、清理灰烬、重新点火。
2. **配菜**：按照食谱找齐鱼、豆腐、红枣、长寿面。厨房里有干扰项（盐罐、海带、空罐头）。
3. **调火**：汤需要“大火煮沸 → 小火慢炖 → 关火焖七分钟”。玩家要操作三个炉门，火候太大会烧干，太小会不熟。失败可重来，不扣东西。
4. **尝味**：Lan 尝汤，触发记忆——小时候的餐桌、母亲的背影、弟弟抢她碗里的鱼。
5. **关火**：火候到后，玩家必须把火关掉。火不关，潮针拿不出来。
6. **取针**：锅底，潮针 4。
7. **记忆闪回**：母亲浑身湿透来厨房，手里拎着 Chao 的鞋，说“他还没吃饭”。
8. ** confession**：Chef Carp 承认自己守了十年火，也知道母亲在骗自己。

**关键选择**：把汤倒掉，或留一碗。  
- 倒掉：灶火彻底熄灭，厨房变冷。  
- 留一碗：第八副餐具旁多一碗汤，真结局晚餐戏多一句。

**获得**：潮针 4、食谱、汤碗（可选）。

**旅馆变化**：厨房不再有蒸汽；餐厅的长桌上第一次摆满七副餐具。

---

### 第五夜 · 摇篮曲（105 / Miss Moth）

**目标**：修好八音盒，弹完摇篮曲，让 Miss Moth 睡着，取回第五枚潮针。

**谜题链**：
1. **修八音盒**：发条断裂。玩家需要在钢琴凳、针线盒、工具箱里找到替换发条。
2. **找音符**：墙上有四张蜡笔画，每张画对应一个音符/颜色。玩家需要把画与钢琴键上的颜色标记对应。
3. **光影**：房间里有三盏灯。玩家调整灯的位置，让飞蛾的影子落在墙上画出的五线谱上，组成旋律。
4. **弹奏**：按顺序点击钢琴键。正确旋律是母亲常哼的摇篮曲；最后一个音必须故意不弹。
5. **Miss Moth 睡着**：她第一次闭眼。面具裂开。
6. **取针**：八音盒发条盒里的潮针 5。
7. **记忆闪回**：雨夜琴声；窗外两个人影跑过；Chao 喊“姐姐等等我”；水声被琴声盖住。
8. ** confession**：Miss Moth 承认自己看见了，也听见了，但没有停。

**关键选择**：叫醒她，或让她睡。  
- 叫醒：她给你额外线索（母亲那晚去了码头）。  
- 让她睡：获得“安眠”flag，真结局她会安静离开。

**获得**：潮针 5、八音盒、节拍器。

**旅馆变化**：105 的灯一盏盏熄灭；走廊里第一次听见海浪声。

---

### 第六夜 · 没有尸体的死亡证明（106 / Dr. Crow）

**目标**：还原 Chao 的死亡时间，修正死亡证明，取回第六枚潮针。

**谜题链**：
1. **检查遗物**：Chao 的蓝外套、一只鞋、一截红线、纸船残片。
2. **药柜整理**：按标签颜色/有效期排列药瓶，找到镇静剂和盐唱片清洗液。
3. **血迹与潮汐**：把外套上的盐渍、血迹、码头照片、潮汐表放在灯箱上比对，推断落水时间在 03:10–03:13。
4. **死亡证明**：填写时间、地点、死因。无论怎么填，尸体一栏只能选“未发现”。
5. **盖章**：玩家必须亲手盖上“确认死亡”或“未确认死亡”的章。  
   - 盖“确认死亡”：程序上完成，但 Dr. Crow 崩溃。  
   - 盖“未确认死亡”：真结局 flag。  
6. **取针**：死亡证明封皮夹层里的潮针 6。
7. **记忆闪回**：Lan 坐在诊疗床上，浑身湿透，反复说“我抓不住他”；母亲在门外说“让她忘了吧”。
8. ** confession**：Dr. Crow 承认自己给 Lan 听了盐唱片。

**关键选择**：烧掉所有死亡证明，或保留档案。  
- 烧掉：真结局中，所有死者被释放。  
- 保留：结局二中，Lan 在档案里找到自己的名字。

**获得**：潮针 6、原始诊断记录、盐唱片（Lan 的记忆）。

**旅馆变化**：六个房间的门同时打开；二楼走廊尽头出现 107。

---

### 第七夜 · 107（Chao）

**目标**：进入 107，和弟弟吃完最后一顿饭，拿到第七枚潮针。

**流程**：
1. 走廊变长。玩家必须走过七扇门，每扇门后传来一位客人的声音。
2. 107 门开着。Chao 坐在桌前，两碗汤，两副碗筷。
3. **晚餐对话**：玩家选择吃什么、说什么。Chao 会问三个问题：
   - “你还记得我的生日吗？”
   - “你那天为什么不等我？”
   - “你这次会留下来吗？”
   回答不改变结局，但改变最后的告别台词。
4. **玩具钟谜题**：桌上的玩具钟停在 03:13。玩家用六枚潮针（暂用）调整齿轮，让钟走到 03:14。  
   - 这一步象征“让时间继续”。
   - 解开后，Chao 拿出第七枚潮针。
5. **真相**：Chao 坦白自己是回声，知道真实的 Little Chao 已经死了。他把纸船和第七枚针交给 Lan。
6. **告别**：Chao 问“你这次会留下来吗？”玩家选择“会/不会/我不知道”。这是情绪选择，不是结局选择。
7. Chao 消失，房间开始漏水。玩家回到大厅。

**获得**：潮针 7、纸船（写有 03:14）、Chao 的蜡笔画。

**旅馆变化**：所有钟停在 03:13；大厅的留声机开始播放母亲的最后一段录音。

---

### 终章 · 03:13（地下室 / 潮钟）

**目标**：面对潮钟，做出最终选择。

**流程**：
1. 地下室门打开。六位客人站在楼梯上。
2. 潮钟前有七个孔。玩家可以自由查看、对话、听母亲的盐唱片。
3. **母亲最后的话**：
   > “我把你弟弟留在最后一分钟里，是因为我不敢让他走。后来我才知道，我留住的不是他，是我自己不肯承认的那句话——是我没有看好他。”
   > “你不要学我。把钟修好，然后走。”
4. **最终谜题**：不是益智题，而是操作选择。玩家必须实际动手：
   - 把七枚潮针插入钟盘；
   - 或者把潮针还给客人；
   - 或者用螺丝刀卡住擒纵器。
5. 根据选择与 flag，播放三种结局之一。

## 四、结局条件

| 结局 | 最终操作 | 前置条件 | 情绪落点 |
|---|---|---|---|
| **一 · 守潮** | 七针插入，顺时针上弦 | 拥有七枚潮针 | 留住弟弟，成为下一任守潮人；循环继续 |
| **二 · 退潮** | 六针归还客人，第七针还给 Chao，让钟自然停 | 完成六位客人的 confession | 放所有人走；Lan 失去记忆，但活下来 |
| **三 · 盐月** | 用螺丝刀卡住擒纵器 | 七针 + 母亲的信 + Chao 的纸船 + 完成全部六位客人的 confession | 打破循环；记住一切；真正的告别 |
| **隐藏 · 白鹭**（可选/后续） | 在灯塔点亮灯 | 找到父亲明信片 + 所有盐唱片 | 暗示父亲去向；为续作留门 |

### Flag 设计

```
has_needle[1..7]
confession[egret, mole, hare, carp, moth, crow] = true/false
kept_photo = true/false
kept_boat = true/false
kept_soup = true/false
slept_moth = true/false
burned_records = true/false
read_mother_letter = true/false
heard_all_records = true/false
```

**提示**：真结局条件不要藏得太深。让 Madam Egret 在第六夜明确说：“如果你想知道你妈妈为什么留下你，去阁楼听完所有唱片。”  
玩家可以错过，但不能毫无提示。

## 六、谜题设计规范

### 难度曲线

| 章节 | 难度 | 类型 | 失败惩罚 |
|---|---|---|---|
| 序章 | 教学 | 点击/对话 | 无 |
| 101 | ★☆☆ | 拆解/路径 | 可重来 |
| 102 | ★★☆ | 测量/逻辑 | 可重来 |
| 103 | ★★☆ | 观察/排序 | 可重来 |
| 104 | ★★★ | 状态管理/顺序 | 可重来，不烧毁道具 |
| 105 | ★★★ | 音画/光影 | 可重来 |
| 106 | ★★★☆ | 推理/证据 | 可重来 |
| 107 | ★☆☆ | 情感/对话 | 无 |
| 终章 | — | 选择 | 不可逆（可读档） |

### 交互规范

- 可交互物体：鼠标悬停时轻微发光/描边，指针变为黄铜钥匙。
- 不可交互但重要的物体：点击后有 Lan 的短句，避免“点了没反应”。
- 物品栏：底部一条旧缝纫盒，最多 8 格；可翻页。
- 组合：把 A 拖到 B 上；正确组合有音效和短动画。
- 对话：点击继续；可跳过已读；关键选择不显示“对/错”。
- 提示：母亲怀表，三段式提示（方向 → 具体位置 → 直接答案）。
- 自动保存：每章开始、获得潮针、结局选择前。
- 无死亡、无倒计时、无随机失败。

### 无障碍

- 所有音频线索都有视觉替代（音乐谜题有颜色/符号）。
- 字幕可调大小；对话可回看。
- 色盲友好：关键颜色配合形状/图案。
- 减少动态：可关闭屏幕抖动、闪烁、雨滴密度。
- 不依赖快速点击。

### 核心 Autoload

| Autoload | 职责 |
|---|---|
| `GameState` | 当前章节、flag、潮针、已读对话、结局条件 |
| `DialogueManager` | 加载 JSON、逐行播放、条件分支、信号 |
| `SaveManager` | `user://save_*.json` 读写；自动存档 |
| `AudioManager` | 音乐/音效/环境音总线；淡入淡出 |
| `SceneRouter` | 场景切换、淡入淡出、加载画面 |
| `HintSystem` | 三段式提示；根据当前谜题状态给文本 |

### 交互实现

```gdscript
# Interactable.gd（示意）
class_name Interactable
extends Area2D

@export var interact_id: String
@export var cursor: String = "key"
@export var required_flag: String = ""
@export var hide_if_flag: String = ""

signal interacted(id: String)

func can_interact() -> bool:
    if required_flag != "" and not GameState.has_flag(required_flag):
        return false
    if hide_if_flag != "" and GameState.has_flag(hide_if_flag):
        return false
    return true

func _on_input_event(_viewport, event, _shape_idx):
    if event.is_action_pressed("interact") and can_interact():
        interacted.emit(interact_id)
```

### 数据驱动

- 对话、物品描述、谜题提示全部放 JSON/CSV，不硬编码在场景里。
- 每个房间一个 `RoomState`，用枚举/字典控制物体显示、对话分支。
- 谜题继承 `PuzzleBase`，统一 `setup() / reset() / solve() / get_hint()` 接口。
- 结局条件集中在一个 `EndingResolver.gd`，避免散落在场景脚本里。

### 美术与音频接入

- 背景：1920×1080 WebP/PNG，16:9，固定机位。
- 角色：分层 PNG（身体/面具/手/阴影），用 `AnimationPlayer` 做呼吸、转头、面具裂纹。
- 水/盐/雨：`ColorRect` + 自定义 shader；不要用大量粒子拖性能。
- 灯光：`CanvasModulate` + `PointLight2D`；每章色调不同。
- UI 分辨率：1280×720 基准，`canvas_items` 拉伸。
- 音频总线：Master / Music / SFX / Ambience / Voice。
- 音频线索必须视觉化；不要做“只听声音”的谜题。

## 十、风险与应对

| 风险 | 应对 |
|---|---|
| 七个房间重复感 | 每章改变旅馆公共区域：挂钟、照片、餐具、灯光、客人位置 |
| 谜题与剧情脱节 | 每个谜题必须先写“它让谁暴露了什么”，再写玩法 |
| 玩家看不懂真相 | 用盐唱片、客人 confession、母亲信件三条线重复关键信息 |
| 真结局条件太隐蔽 | Madam Egret 在第六夜给明确提示；结局选择前可回看档案 |
| 美术量过大 | 固定机位、单房间、分层角色、复用公共区域；先做灰盒 |
| 恐怖感依赖 jump scare | 禁用突然音效；用重复、错位、空白和等待制造不安 |
| 移动端点击不准 | 热点最小 48×48 px；靠近自动吸附；支持双击放大 |
