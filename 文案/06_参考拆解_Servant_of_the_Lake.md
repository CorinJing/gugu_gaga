## 二、它的整体结构

从攻略章节和画面看，它不是一个“房间—钥匙—出口”的密室，而是**一份工作日**：

```
抵达宅邸
  → 准备早餐
  → 唤醒 Aldous
  → 迎宾准备
  → 迎接宾客
  → 侍奉茶水
  → 聚会开幕
  → 夜巡
  → 搜寻阁楼
  → 准备咖啡
  → 唤醒 William
  → 清扫
  → 外出狩猎
  → 洗衣
  → 协助入浴
  → 夜间勤务
  → 探查地窖
  → 寻找猫咪
  → 协助炼金
  → 紧急维修
  → 准备晚宴
  → 更衣
  → 侍奉晚宴
  → 恭送宾客
```

这不是任务清单的简单堆叠。它的节奏是：

**日常 → 更日常 → 一个小异常 → 继续日常 → 异常变大 → 进入夜间/地窖/炼金 → 无法回头。**

玩家始终在“上班”。恐怖不是突然闯进来的，而是从家务的缝隙里渗出来的。

## 三、十个设计观察

### 1. 仆人视角：看得见一切，却几乎没有权力

玩家是仆人，不是侦探。仆人必须进入每个房间、整理每个人的私人物品、知道每个人的习惯，却不能被允许发问。

这带来一种很强的戏剧反讽：

- 玩家知道得比客人多；
- 玩家能做的事却比客人少；
- 玩家越尽责，越接近秘密；
- 玩家越接近秘密，越成为共犯。

这比“我是天选侦探”更接近 Rusty Lake 的气质，也让家务不再是填充内容。

### 2. 家务就是谜题语法

它的谜题不是“先找三把钥匙”，而是：

- 摆早餐；
- 磨咖啡；
- 给钟上弦；
- 整理肖像；
- 洗衣；
- 给客人放洗澡水；
- 清理现场；
- 配药。

这些动作本身有步骤、有工具、有先后关系，天然适合点击式解谜。玩家不需要被教导“这是谜题”，因为家务本来就是谜题。

### 3. 每件物品都有声音

官方声音 devlog 明确说：几乎每件物品、家具都有独立音效；每个空间有自己的声音身份。

这会让“点击”从抽象操作变成**触摸**：

- 木头有木头的响；
- 布料有布料的响；
- 金属、纸张、水、瓷器各不相同；
- 同一间房在不同时间的声音也不同。

这是我们的第一版最值得补的一课。我们已经有针、剪刀、汤锅、钟，但还缺少“每个物件都值得点一下”的触感。

### 4. 镜头是“近距离观看”，不是“房间全景”

它的画面大量使用：

- 单物件特写；
- 桌面静物；
- 肖像/画中画；
- 门缝/钥匙孔；
- 局部身体；
- 突然推近的脸。

房间全景通常只用于“进入/离开”，真正解谜时镜头会贴近物体。这样：

- 谜题物件看得清；
- 画面更有压迫感；
- 玩家不需要在背景里像素级寻找；
- 每个谜题都像一件被端到面前的展品。

我们的缝纫机和红线谜题目前是“覆盖式面板”，可以改成“镜头推近真实物体”的处理，让房间在四周暗下去，而不是完全消失。

### 5. 文本很省，靠画面和动作补

游戏有配音和文本气泡，但很少长篇解释。角色说话短、冷、带黑色幽默；玩家通过：

- 角色站的位置；
- 谁不看谁；
- 物品被谁碰过；
- 房间里多出来的东西；
- 前后两次进入同一房间的差异；

来理解关系。

这和我们第一版形成明显对比：我们的 Madam Egret 会直接解释“你妈妈把针缝进机器里”。这句话可以保留，但更好的顺序是先让玩家看见红线和衣领，再由角色补一句更短的话。

### 6. 日常与身体恐怖的反差

它的恐怖不是全程压着，而是：

- 先让你摆餐具、磨咖啡、叠衣服；
- 然后突然出现器官、血、畸形的身体、诡异的炼金物；
- 角色仍然用非常日常的语气谈论这些事。

恐怖来自**语气和内容的不匹配**：他们把这些当成家务的一部分。

我们的《盐月旅馆》不需要走血腥路线。我们可以用更克制的“身体异常”：

- 面具下的脸被盐粘住；
- 客人的手指缝在一起；
- 汤里煮着一颗乳牙；
- 钟摆里泡着一个孩子的牙齿；
- 湿脚印从走廊一直延伸到墙里。

关键是：**角色不惊讶**。玩家才会害怕。

### 7. 章节卡与时间感

攻略里能看到明显的章节卡（如 “Chapter 1 / Chapter 2 The Departure”），黑底、繁复边框、白字，像一本旧书或戏单。

章节卡的作用不是装饰，而是：

- 告诉玩家“时间过去了”；
- 把长流程切成可呼吸的段落；
- 给重复的家务一个节奏；
- 让“夜晚/离开/归来”有仪式感。

我们的“第一夜”也可以有自己的章节卡：黑底、盐霜边框、标题“第一夜 / 红线”，配一声钟或潮声。

### 8. 侧边物品栏与“舞台”留白

它的 UI 很克制：物品栏在侧边，对话是短气泡，画面主体仍然是舞台。玩家不会觉得一半屏幕被 UI 吃掉。

我们的第一版是底部物品栏 + 大幅对话面板。对白多的时候，画面会被压得很低。可以尝试：

- 侧边“缝纫盒”式物品栏；
- 对话气泡靠近角色/物件；
- 对话时保留更多场景；
- 重要独白用全屏文字卡，而不是一直占着对话框。

不需要照抄它的布局，但需要让 UI 退后，让房间成为主角。

### 9. 真实绘画与分层视差

官方美术 devlog 提到：背景由画家 Johan Scherft 用铅笔和水彩创作，并把山、草地、湖等元素画在独立裁切的画布上，在镜头前叠出 3D 视差。

这给我们的启发不是“也去画水彩”，而是：

- 用**分层**制造空间：前景、中景、背景分开；
- 用轻微视差/镜头移动让静态场景活起来；
- 让室外场景有呼吸；
- 让“画”本身成为叙事物件（肖像、画中画、被遮住的脸）。

我们的纸剧场风格可以用同样的方法：前景的窗帘、桌上的物件、窗框、盐雾分层，镜头轻微横移时产生层次。

### 10. 长流程靠“重复中的变化”支撑

同一个大厅、同一张餐桌、同一间卧室，会在不同时间反复出现。玩家记住的是：

- 第一次桌上摆了什么；
- 第二次少了谁；
- 第三次多了一副餐具；
- 第四次墙上多了一幅画。

这比不断开新地图更有效，也更适合小团队。

我们的旅馆已经有这个潜力：大厅、餐厅、走廊、101–107。下一步应该让这些空间在七夜里**持续变化**，而不是每章换一张新背景。

## 四、与《盐月旅馆》的对照

| 维度 | Servant of the Lake | 《盐月旅馆》第一版 | 结论 |
|---|---|---|---|
| 玩家身份 | 新来的仆人/管家 | 回家继承旅馆的女儿/修表匠 | 都是“被雇佣/被家庭绑住”的观察者；我们的身份更有情感债 |
| 核心循环 | 一天的家务 → 宾客 → 夜间 → 炼金 | 一夜一房 → 找工具 → 解谜 → 取潮针 | 我们更章节化；需要补“日常感” |
| 空间 | 宅邸 + 花园 + 地窖 | 旅馆 + 客房 + 地下室 | 都适合小团队；我们的空间更集中 |
| 谜题 | 家务、摆设、顺序、配药、机关 | 缝纫、测量、显影、烹饪、音乐、验尸 | 方向一致；我们的谜题隐喻更强 |
| 文本 | 短气泡、配音、少解释 | 大对话盒、解释较多 | 我们需要减字 |
| 恐怖 | 身体恐怖 + 黑色幽默 | 忧郁、盐、记忆、家庭 | 保留我们的气质；加一点“日常中的异常” |
| 美术 | 手绘、油画肖像、分层视差 | 平面 SVG、纸剧场、颗粒 | 需要主动向它靠拢：手绘质感、低饱和、舞台式构图；设定仍原创 |
| UI | 侧边物品栏、小气泡 | 底部物品栏、大对话盒 | 从“底部大栏”改成“侧边物品栏 + 短气泡” |
| 恐怖 | 身体恐怖 + 黑色幽默 | 忧郁、盐、记忆、家庭 | 保留忧郁，但增加“日常中的异常”与冷幽默，不必照搬血腥 |
| 节奏 | 长流程、重复空间、章节卡 | 短切片、单房间、结束卡 | 先做“更厚的 101”，不要盲目加长 |

**关键修正：** 这里不是“只学结构、风格保持原样”。如果目标是风格类似，那么**画幅、构图、UI、文本气泡、声音、色彩、镜头语言都要一起靠拢**；只是不照搬它的具体设定与资产。

## 五、如果目标是“风格类似”，具体要对齐什么

先分清两层：

- **风格层**：可以主动靠拢，甚至刻意相似。手绘、低饱和、舞台式构图、侧边物品栏、短气泡、室内乐、物件音效、日常恐怖——这些是“语言”。
- **内容层**：必须原创。Vanderboom 家族、Aldous/William/Alexandra、炼金术、动物头晚宴、具体谜题与台词，都不拿。

### 5.1 画面与构图

| 项目 | 目标 |
|---|---|
| 画幅 | 4:3 舞台，或 16:9 内嵌 4:3 画框；外侧留黑边/暗角 |
| 材质 | 水彩/水粉感、铅笔底稿、纸张纹理、轻微笔触不均 |
| 色彩 | 鼠尾草绿、灰粉、奶油白、铁锈红、芥末黄、墨黑；低饱和 |
| 角色 | 略长的脸、克制的表情、油画质感的肖像；不是扁平剪影 |
| 镜头 | 房间全景用于进出；解谜时推近物件，背景保留暗角 |
| 光影 | 暖黄台灯/壁炉 + 冷绿环境；柔和阴影，不追求写实 |
| 室外 | 2–3 层视差：远山/湖、旅馆中景、前景草/栏杆 |

### 5.2 UI 与交互

| 项目 | 目标 |
|---|---|
| 物品栏 | 右侧纵向“缝纫盒/钥匙板”，小图标；选中时金色描边 |
| 对话 | 角色附近的短气泡 + 小头像；不要整块底部对话框 |
| 旁白 | 屏幕上方/下方一行小字，或全屏章节卡 |
| 章节卡 | 黑底、盐霜/黄铜边框、白字；配钟声/潮声 |
| 光标 | 黄铜钥匙/手指；悬停时物件轻微发光 |
| 解谜 | 物件特写占满舞台；关闭时回到房间，不切独立 UI |

### 5.3 声音

| 项目 | 目标 |
|---|---|
| 音乐 | 钢琴、竖琴、长笛、八音盒、低音弦乐；一个主题多房间变奏 |
| 环境 | 每间房一条底噪：雨、木头、钟、火、琴、药瓶、海 |
| 物件 | 布料、木桌、剪刀、针、纸张、瓷器、门把手、盐粒都有独立触感 |
| 人声 | 母亲盐唱片用低语/失真；客人用短句/气声；不必全语音 |
| 留白 | 关键真相时抽掉音乐，只留钟/潮/呼吸 |

### 5.4 文本与表演

- 短句优先。每句只做一件事：推进、暴露、或留白。
- 少解释设定，多让物件和动作说话。
- 角色用日常语气谈论异常；黑色幽默来自“他们觉得很正常”。
- 角色有重复动作；动作变化时，才给一句新台词。
- 不用大段内心独白；Lan 的内心用“修理动作”表达。

### 5.5 第一版现状 vs 目标

| 项目 | 第一版现状 | 风格目标 |
|---|---|---|
| 画幅 | 16:9 全屏 | 4:3 舞台 + 侧边栏，或内嵌画框 |
| 美术 | 扁平 SVG、纸剧场 | 手绘水彩/水粉、铅笔线、纸纹 |
| 角色 | 扁平面具/剪影 | 油画感肖像、柔和阴影、微表情 |
| UI | 底部物品栏 + 大对话盒 | 侧边物品栏 + 短气泡 |
| 谜题 | 独立深色面板 | 推近真实物件，房间暗角保留 |
| 声音 | 程序化环境音/八音盒 | 室内乐 + 每物件 foley + 房间底噪 |
| 文本 | 解释较多 | 短句、冷幽默、少解释 |
| 节奏 | 单房间切片 | 值班表、章节卡、夜间仪式 |

### 5.6 建议先做的“风格样张”

先不改剧情、不加第二夜，只重做 **101 号房的一张画面 + 一段对话 + 一个谜题**：

- 4:3 舞台 + 右侧物品栏；
- 手绘质感背景（哪怕先用纹理/笔触近似）；
- 缝纫机推近特写，红线从机器延伸到衣领；
- Madam Egret 的对话缩短到 3–4 句；
- 布料、剪刀、针、木头各有声音；
- 结尾加一张“第一夜 / 红线”章节卡。

这张样张通过后，再批量重绘其他房间。否则很容易出现“剧情是新的，视觉还是旧的第一版”的割裂。

## 六、对第一版的具体修改建议

### P0：下一版一定要做

1. **把“值班表”做成叙事道具**  
   不要做通用任务栏。用旅馆登记簿/值班卡：每晚一页，列出 3–5 件家务。完成一项盖一个章。  
   例：101 夜班：送茶、补外套、修缝纫机、理红线、熄灯。

2. **给 101 增加“日常前戏”**  
   现在一进门就是修机器。可以先让玩家：
   - 把 Madam Egret 的茶放在桌上；
   - 捡起地上的线轴；
   - 拉开窗帘；
   - 给衣架上的小外套掸灰；
   - 然后才发现机器卡住。  
   这些动作不需要复杂谜题，但会让房间有生活痕迹。

3. **让谜题镜头“进入物体”**  
   缝纫机谜题不要用一块全新的深色面板，而是从房间背景推近到真实机器，四周保留房间的暗角。红线谜题也应该是“桌上的线圈特写”，而不是独立 UI。

4. **减少 30% 的解释性对白**  
   保留关键台词，删掉“说明设定”的句子。让玩家先看见，再让角色说一句短话。  
   例如 Madam Egret 不必解释“你妈妈把第一根针缝进机器里”，可以先让镜头停在红线、衣领、针鼻的“1”上。

5. **每个可点物件都有声音**  
   至少补：布料、木桌、金属剪刀、纸张、瓷器、门把手、窗框、盐粒。  
   不是每个都要独特到昂贵，但要让点击有触感。

### P1：值得做

6. **章节卡与夜间仪式**  
   每夜开始：黑底章节卡 + 钟声/潮声；每夜结束：关灯、锁门、听 107 的动静。形成重复仪式。

7. **大厅作为“活着的枢纽”**  
   每完成一夜，大厅变化：多一杯茶、少一位客人、墙上的照片换了、挂钟倒退一分钟、餐桌上多一副餐具。玩家会主动回去看。

8. **缩小对话框，增加“物件旁白”**  
   对话气泡靠近说话者；单独调查物件时，用屏幕下方一行小字，不打开完整对话框。  
   这样房间不会被 UI 压住。

9. **给客人设计“重复动作”**  
   白鹭缝衣、鼹鼠量尺寸、Mr. Hare 擦镜头、Chef Carp 搅汤、Miss Moth 调灯、Dr. Crow 折纸。玩家每次进大厅都能看到他们在做同一件事，直到某一夜动作变了。

10. **加一点黑色幽默**  
    我们的故事偏忧郁。适当加入客人对异常事物的日常化反应，会让恐怖更有效。  
    例：Mr. Mole 量完棺材，问“你弟弟喜欢朝南还是朝北？”

### P2：以后再做

11. **侧边物品栏实现**  
    这不再只是“可选实验”，而是风格目标的前置条件：右侧“缝纫盒”纵向物品栏，底部释放给场景。先做 101 的 A/B 样张，再决定是否全局替换。

12. **分层视差**  
    室外渡口、旅馆外观、走廊可以做 2–3 层轻微视差；室内保持固定机位，避免过度运动。

13. **声音身份**  
    每个房间一个环境底噪：101 雨/缝纫机、102 泥土/皮尺、103 显影液/快门、104 火/汤、105 琴/飞蛾、106 药瓶/钟、107 海/纸船。

## 七、风格与内容的边界：可以学什么，不能拿什么

**可以学（风格层）：**

- 手绘水彩/水粉质感、铅笔线、纸纹、低饱和配色；
- 4:3 舞台、圆角画框、暗角、侧边物品栏、短气泡；
- 物件特写、静物构图、分层视差、章节卡；
- 室内乐、每物件独立音效、房间底噪、低语/配音；
- 日常家务 → 异常升级的节奏，仆人/旁观者视角，冷幽默。

**不能拿（内容层）：**

- Vanderboom 家族、Aldous/William/Alexandra、炼金术与灵药设定；
- 动物头客人、旅馆晚宴、记忆方块、湖中巨物等 Rusty Lake 标志性符号；
- 具体谜题答案、房间构图、UI 皮肤文件、角色台词、美术资产；
- 它的血腥身体恐怖；我们走“盐、潮湿、记忆、家庭”的克制恐怖；
- 不为了“像 Rusty Lake”而增加无意义的怪诞；每个异常都要能在情感上解释。

---

## 八、一句话结论

《Servant of the Lake》最值得学的不是“动物头”或“怪谜题”，而是：

> **让玩家先做一个仆人该做的事，再让他发现这个家不正常。**  
> **家务越具体，恐怖越真实；文本越少，房间越会说话。**

对《盐月旅馆》来说，这意味着：

- 不要急着加更多房间；
- 先把 101 号房做得更像“真的有人在里面生活”；
- 让缝纫机、红线、衣领、茶、灯、雨都成为可触摸的东西；
- 让玩家在修机器之前，先学会在这个房间里当一晚仆人。
