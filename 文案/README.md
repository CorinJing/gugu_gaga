## 这是什么

这里是《盐月旅馆》的**叙事圣经**，也是后续美术、谜题、程序开发的共同底稿。

故事发生在一座被盐雾包围的海滨小镇。离家十年的修表匠 Lan，回到母亲留下的七室旅馆，必须在七个夜晚里走完七间客房、取回七枚“潮针”，才能让地下室那口停在 **03:13** 的钟重新走动。

每取回一枚潮针，她就离十年前那个被海水抹去的夜晚更近一步——以及那个本该死去、却仍在 **107 号房**等她的弟弟。

## 阅读顺序

1. 先读 **01_创作思路**，理解“为什么是这样一个故事”。
2. 再读 **02_世界观设定**，记住盐、潮、钟三条规则。
3. 然后读 **03_背景故事**，这是游戏剧情的完整底稿。
4. 开发时以 **04_人物与客房** 和 **05_游戏流程与谜题蓝图** 为工作手册。
5. **06** 是外部参考拆解，不属于本作设定，但可以作为下一轮打磨的对照。

> **剧透警告**：02 之后包含完整真相。若只想体验故事，先读 03。

## 核心主题

- **记忆是否等于存在**：如果一个人只活在别人的记忆和一间循环的房间里，他还算活着吗？
- **爱与控制的一体两面**：母亲用“留住”表达爱，也用“留住”囚禁了所有人。
- **告别的能力**：真正的修复，有时不是让钟重新走，而是允许它停下。
- **家作为牢笼，也作为最后的避难所**。
